Tento veřejný repozitář obsahuje dřívější snímek kvantitativní aplikace QuanuX s cílem předběžného vydání v0.0.1-pre. Jeho README popisuje server v Pythonu, klientské nástroje Node/pnpm a cestu vývoje desktopové aplikace v Tauri.

## Rozlišujte vydání {#keep-the-releases-distinct}

Dřívější balíček Conda quanux a pokyny k nastavení aplikace patří k tomuto snímku. Nejsou cestou instalace Symphony Public Beta 0.2.0-beta.1.

Pro aktuální nativní vydání Symphony použijte [stažení Symphony a přesné profily Anacondy](https://quanux.org/downloads) a [průvodce testováním bety](https://quanux.org/beta).

## Prozkoumejte snímek {#explore-the-snapshot}

Při zkoumání architektury nebo reprodukci historického chování používejte README, licenci, manifesty závislostí a zaznamenanou revizi zdrojového kódu tohoto repozitáře. Jeho experimentální API a aplikační model se nesmí tiše přenášet do aktuální architektury Symphony ani do tvrzení o připravenosti.
