Symphony je open-source quantOS vyvíjený podle Vector-Graph Application Architecture. Nativní enginy a SDK vykonávají doménovou práci; qxctl poskytuje agentům i lidem společné řídicí rozhraní. Uživatelé si volí vlastní enginy, strategie, poskytovatele a topologii.

## Veřejná beta {#public-beta}

Publikované vydání je **0.2.0-beta.1**, spuštěné 16. listopadu 2026. Poskytuje 59 výchozích balíčků na přesný profil, nativního klienta Codex, exporty SDK a volitelný odpovídající zdrojový kód.

| Cíl | Architektura |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

Začněte [stažením a pokyny pro Anacondu](https://quanux.org/downloads) a poté použijte [průvodce funkcemi a testováním bety](https://quanux.org/beta).

## Funkce k prozkoumání {#capabilities-to-explore}

- Manifesty qxctl, verze, kontrola nainstalovaných vlastníků a explicitní správa.
- Zachytávání, metadata, tok, převod na celá čísla, lokální úložiště, přehrávání a kontrolní body SQV.
- Ohraničený výzkum backtestů, sčítání, nativní vyhodnocení, uchované výsledky, zrušení a obnova SBV.
- Katalogy hardwaru podložené zdroji, požadavky, grafy a náhledy publikace SHV.
- Znalosti o poskytovatelích SCV a identita Node, prostředky, vztahy v clusteru a pojmenování SNV.
- Autorizace SSIAG, auditní důkazy STAV, kompozice a správa znalostí.

## Hranice kvalifikace {#qualification-boundaries}

Záznam o vydání identifikuje přesné kvalifikované bajty. Fyzický DGX Spark, chování GPU a produkční nasazení u poskytovatelů vyžadují samostatné důkazy. Obecné doručování přihlašovacích údajů a nativní mosty k poskytovatelům mají výslovně uvedené mezery v implementaci; instalace adaptéru nekvalifikuje produkční připojení. Opravy v hlavní větvi zdrojového kódu nenahrazují podepsané artefakty bety.

Před provozováním každého zvoleného modulu si přečtěte [aktuální README zdrojového kódu a poznámky k údržbě](https://github.com/QuanuX/Symphony#readme) a jeho specifikaci.
