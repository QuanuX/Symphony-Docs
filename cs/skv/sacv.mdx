Symphony API Contract Vector (SACV) spravuje verzované API kontrakty napříč platformou. Jeho engine je nezávisle instalovatelný proces v C++, který provádí ohraničenou validaci JSON podle OpenAPI 3.2.0, deterministické rozdíly kompatibility a jednorázové inventáře. Sémantika koncových bodů zůstává u vektoru nebo modulu, který vlastní danou doménu; SACV spravuje tvar a kompatibilitu kontraktů.

## Operace

- **Inspect a check**: ověří, že dokument JSON podle OpenAPI 3.2.0 odpovídá ohraničenému profilu.
- **Diff**: vypočítá deterministické rozdíly kompatibility mezi verzemi kontraktů.
- **Propose**: přijímá návrhy registru deklarované volajícím pro nové nebo změněné kontrakty.
- **Project**: emituje jednorázové inventáře pro recenzenty a navazující nástroje.

## Co SACV spravuje

SACV ohraničuje:

- Tvar kontraktu (OpenAPI 3.2.0 s profilem SACV)
- Klasifikaci kompatibility mezi verzemi
- Členství přijatých kontraktů v registru

SACV naopak:

- Nevlastní sémantiku koncových bodů (tu si ponechává každý vektor nebo modul)
- Negeneruje SDK, nepublikuje artefakty ani nevydává tokeny
- Neimplikuje existenci živé síťové plochy (zmínka o budoucím privátním API žádné nevytváří)

<Note>
  SACV slouží pouze ke čtení, dotazování, validaci a navrhování. Programové kanonické apply je napříč enginy SKV zakázáno.
</Note>
