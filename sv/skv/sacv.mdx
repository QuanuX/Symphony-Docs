Symphony API Contract Vector (SACV) styr versionerade API-kontrakt över hela plattformen. Dess motor är en oberoende installerbar C++-process som utför avgränsad JSON-validering enligt OpenAPI 3.2.0, deterministiska kompatibilitetsdiffar och engångsinventeringar. Slutpunktssemantik ligger kvar hos den domänägande vektorn eller modulen; SACV styr kontraktets form och kompatibilitet.

## Operationer

- **Inspect och check**: validerar att ett OpenAPI 3.2.0 JSON-dokument följer den avgränsade profilen.
- **Diff**: beräknar deterministiska kompatibilitetsdiffar mellan kontraktsversioner.
- **Propose**: tar emot anroparens deklarerade registerförslag för nya eller ändrade kontrakt.
- **Project**: avger engångsinventeringar för granskare och nedströmsverktyg.

## Vad SACV styr

SACV avgränsar:

- Kontraktets form (OpenAPI 3.2.0 med SACV-profilen)
- Kompatibilitetsklassificering mellan versioner
- Registermedlemskap för accepterade kontrakt

Det gör inte följande:

- Äger slutpunktssemantik (varje vektor eller modul behåller den)
- Genererar SDK:er, publicerar artefakter eller utfärdar token
- Antyder att en aktiv nätverksyta finns (att ett framtida privat API nämns skapar inte ett sådant)

<Note>
  SACV är endast till för läsning, frågor, validering och förslag. Programmatisk kanonisk apply är inaktiverad i alla SKV-motorer.
</Note>
