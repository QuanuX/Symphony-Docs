El grup `qxctl knowledge ...` s'encarrega del cicle de vida entre vectors i de l'administració de sessions SSFV persistents. És el punt d'entrada per a les operacions recolzades pel coordinador i per a les consultes d'invariants contra el validador.

## Transició de sessió

Feu servir `qxctl knowledge session transition` per senyalitzar un esdeveniment del cicle de vida de l'amfitrió a una sessió existent:

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

Els reintents segurs reutilitzen el mateix identificador d'esdeveniment. Afegiu `--recover` només quan es pretengui una recuperació per descobriment a partir d'evidència local de sessió malmesa; no recupera denegacions, estats crítics incompatibles ni ambigüitats.

<Warning>
  Symphony no instal·la cap hook d'inici de sessió, vigilant ni unitat d'arrencada mitjançant aquesta ordre. Feu-la servir només quan una integració explícita amb el cicle de vida de l'amfitrió proporcioni una identitat d'esdeveniment estable.
</Warning>

## Consultes d'invariants

Quatre fulles vinculen `ssfv:symphony:qxctl.invariant-assurance`:

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` vincula, a més, `ssfv:symphony:symphony-validator.invariant-ownership-assurance`.

Les fulles de consulta directa emeten `symphony.knowledge.invariant-query-result.v1` amb `semantic_validity=not_asserted`. `check` retorna el resultat exacte i complet del validador i preserva el codi de sortida 26.
