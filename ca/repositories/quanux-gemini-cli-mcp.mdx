Aquest repositori conté una extensió de Gemini CLI per a l'aplicació QuanuX anterior. El seu README descriu com carregar el context de GEMINI.md, generar paquets d'estratègies en Python a server/strategies i comprovar l'estat del motor d'execució.

## Avaluació del codi font {#source-evaluation}

El repositori descriu les dependències de Python i com enllaçar l'extensió amb Gemini CLI. Llegiu el README i els fitxers de dependències actuals, reviseu l'extensió i proveu-la amb la instantània de l'aplicació corresponent en un espai de treball aïllat.

## Relació amb Symphony {#relationship-to-symphony}

Aquest projecte és diferent del client beta natiu de Symphony i no estableix compatibilitat amb el conjunt de paquets signat 0.2.0-beta.1. Per al client de Symphony qualificat actual, utilitzeu [les baixades de la beta i la configuració del client](https://quanux.org/downloads). Tracteu els camins de l'aplicació antiga i els exemples d'ordres com a propis d'aquest repositori, no com a contractes universals de Symphony.
