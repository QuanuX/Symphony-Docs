Aquest repositori públic conté una instantània anterior de l'aplicació quantitativa QuanuX, amb un objectiu de prellançament v0.0.1-pre. El seu README descriu un servidor en Python, eines de client amb Node/pnpm i un camí de desenvolupament d'escriptori amb Tauri.

## Mantingueu separades les versions {#keep-the-releases-distinct}

El paquet Conda quanux anterior i les instruccions de configuració de l'aplicació pertanyen a aquesta instantània. No són la via d'instal·lació de Symphony Public Beta 0.2.0-beta.1.

Per a la versió nativa actual de Symphony, utilitzeu [les baixades de Symphony i els perfils exactes d'Anaconda](https://quanux.org/downloads) i [la guia de proves de la beta](https://quanux.org/beta).

## Exploreu la instantània {#explore-the-snapshot}

Utilitzeu el README, la llicència, els manifests de dependències i la revisió de codi font registrada d'aquest repositori quan investigueu la seva arquitectura o reproduïu el seu comportament històric. Les seves API experimentals i el seu model d'aplicació no s'han de promoure silenciosament a l'arquitectura actual de Symphony ni a afirmacions de preparació.
