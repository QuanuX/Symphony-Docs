Els motors de coneixement de fonts SCV són vuit processos C++26 empaquetats de manera independent que contenen coneixement semàntic privat sobre els recursos, les ofertes, les regions, les restriccions i les possibilitats híbrides dels proveïdors externs. Conserven les revisions exactes de les fonts i captures acotades perquè les eines posteriors puguin reproduir-ne els resultats.

## Què fan els motors SCV

- Conserven revisions explícites de les fonts i captures acotades
- Retenen afirmacions qualificades i l'estructura nativa dels documents
- Produeixen evidència reproduïble de grafs i consultes
- Alimenten paquets portables de proveïdors i una composició finita dirigida per l'invocador

## Què no fan

<Warning>
  Les operacions amb proveïdors i els catàlegs complets del núvol queden fora d'aquest increment. Els motors SCV descriuen el que se sap; no actuen sobre els proveïdors.
</Warning>

qxctl administra per separat els canvis auditats de les fonts locals i la selecció coherent de grafs mitjançant fluxos de treball retinguts i una selecció de grafs protegida. El recorregut dedicat de grafs i els adaptadors operatius continuen sent treball independent.
