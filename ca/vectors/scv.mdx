El Symphony Cloud Vector (SCV) és propietari del coneixement semàntic privat sobre recursos de maquinari externs i sobre les realitats dels proveïdors que configuren els vostres clústers i el vostre treball d'entrenament, recerca i dades. Mapeja les ofertes dels proveïdors, les regions, els dominis d'infraestructura, les restriccions i la disponibilitat observada sense classificar proveïdors ni imposar límits a allò que podeu intentar.

## Cobertura de proveïdors

SCV cobreix els proveïdors i tipus de recursos següents:

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- Maquinari propietat de l'usuari (quan cal comparar-lo amb recursos externs)

## Paquets de proveïdor portables i composició

SCV exposa paquets de proveïdor portables mitjançant qxctl. Conserveu el control sobre els requisits, els permisos dels proveïdors, les receptes alternatives i les decisions d'execució. qxctl admet fluxos de treball retinguts i selecció protegida de grafs, de manera que podeu reproduir evidència exacta sense tornar a consultar els proveïdors.

## Connector opcional de DuckDB

El `scv-graph-duckdb-connector` afegeix una projecció relacional acotada dels grafs natius immutables. DuckDB és la base de dades SQL predeterminada seleccionada per l'usuari. En el futur podreu seleccionar motors de grafs dedicats mitjançant adaptadors addicionals.

## Privadesa i sobirania

Un graf de coneixement SCV instal·lat pertany a la vostra instal·lació privada. Els comptes, saldos, permisos i restriccions contractuals aportats per l'usuari només s'utilitzen mitjançant superfícies d'observació habilitades explícitament. Els fets privats no entren a la veritat de codi font oficial de Symphony.

## Increments d'interfície versionats

Les versions de SCV són additives i amb versions exactes. Les instal·lacions anteriors continuen sent invocables en els seus àmbits exactes. Els increments actuals inclouen operacions natives, instantànies de corpus, perfils d'interpretació, paquets de proveïdor portables, fluxos de treball de composició, seguiment d'obligacions i paquets d'evidència. Cada increment preserva les rutes, els valors predeterminats i els registres anteriors.
