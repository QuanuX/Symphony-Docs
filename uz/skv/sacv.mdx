Symphony API Contract Vector (SACV) platforma bo'ylab versiyalangan API shartnomalarini boshqaradi. Uning engine'i mustaqil o'rnatiladigan C++ jarayoni bo'lib, cheklangan OpenAPI 3.2.0 JSON tekshiruvi, deterministik moslik farqlari va bir martalik inventarlarni bajaradi. Endpoint semantikasi domenga egalik qiluvchi vektor yoki modulda qoladi; SACV esa shartnoma shakli va mosligini boshqaradi.

## Amallar

- **Inspect va check**: OpenAPI 3.2.0 JSON hujjati cheklangan profilga mos kelishini tekshirish.
- **Diff**: shartnoma versiyalari o'rtasida deterministik moslik farqlarini hisoblash.
- **Propose**: yangi yoki o'zgartirilgan shartnomalar uchun chaqiruvchi e'lon qilgan reyestr takliflarini qabul qilish.
- **Project**: ko'rib chiquvchilar va quyi oqim vositalari uchun bir martalik inventarlarni chiqarish.

## SACV nimalarni boshqaradi

SACV quyidagilarni cheklaydi:

- Shartnoma shakli (SACV profili bilan OpenAPI 3.2.0)
- Versiyalar o'rtasidagi moslik tasnifi
- Qabul qilingan shartnomalarning reyestrga a'zoligi

U quyidagilarni qilmaydi:

- Endpoint semantikasiga egalik qilish (har bir vektor yoki modul ularni o'zida saqlaydi)
- SDK yaratish, artefaktlarni nashr etish yoki tokenlar berish
- Jonli tarmoq interfeysi mavjudligini nazarda tutish (kelajakdagi xususiy API haqida eslatish uni yaratmaydi)

<Note>
  SACV faqat o'qish, so'rov, tasdiqlash va taklif qilish uchun. Dasturiy kanonik qo'llash SKV engine'lari bo'ylab o'chirilgan.
</Note>
