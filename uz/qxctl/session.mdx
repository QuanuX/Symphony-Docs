`qxctl knowledge session ...` grammatikasi bitta aniq bog'langan koordinator va bitta TOPS doirasidagi SSIAG endpoint'i orqali kanonik bo'lmagan autentifikatsiyalangan sessiyalarni ochadi. Alohida `session features ...` grammatikasi doimiy SSFV texnik xizmat oqimini boshqaradi.

## Asosiy sessiya grammatikasi

```bash Session lifecycle
qxctl knowledge session begin
qxctl knowledge session status
qxctl knowledge session checkpoint
qxctl knowledge session close
qxctl knowledge session recover
```

Har bir chaqiruv yangi aniq ruxsatnoma (grant) so'raydi va quyidagilarni tasdiqlaydi:

- Subyekt va maqsad identifikatori
- Siyosat va konfiguratsiya holati
- Amal qilish muddati
- Chaqiruvchi sinfiga nisbatan neytrallik
- Boshqaga o'tkazib bo'lmaslik
- Kanonik qo'llashning o'chirilganligi
- Imkoniyatga bog'lanish

Sessiya dalillari faqat nomlangan himoyalangan kanonik bo'lmagan amalni avtorizatsiya qiladi. Sessiya va muvofiqlashtirish jurnallarini alohida saqlang; ularni bog'lash uchun faqat kontekst havolalaridan foydalaning.

## SSFV texnik xizmat oqimi

```bash Features stream
qxctl knowledge session features begin
qxctl knowledge session features status
qxctl knowledge session features checkpoint
qxctl knowledge session features close
qxctl knowledge session features recover
```

Features oqimi — alohida doimiy SSFV texnik xizmat konteksti. O'zgarishlar quyidagilarni talab qiladi:

- Ochiq autentifikatsiyalangan asosiy sessiya
- Aniq koordinator va SSFV bog'lashlari
- Barqaror amal identifikatorlari
- Aniq compare-and-swap
- Yangi SSIAG dalillari

<Note>
  Mos keluvchi yangilash yoki orqaga qaytarishlarda boshlang'ich snapshot va uning asl engine identifikatorini saqlang. Ixtiyoriy Maestro dalillari to'liq autentifikatsiyalangan inventar bo'lishi kerak; Maestro ataylab mavjud bo'lmaganda, aniq "sozlanmagan" sababini qayd eting. `review_required` — tasdiqlash emas, balki chaqiruvchi ko'rib chiqishi uchun dalil.
</Note>
