`qxctl validate ...` グラマーは、Symphony Validator の保護された警告ポリシー、ベースライン、表示グラマーを管理します。独立してインストールされる C++ バリデーターは不変の生エビデンスを生成し、qxctl は検出内容を変えることなく、呼び出し元に中立な保護された表示を管理します。

## qxctl validate の対象範囲

- 9 つの保護された警告ライフサイクルリーフ
- レシートに裏付けられた正確なルートサマリールート
- ベースライン管理と差分レポート
- 行出力と構造化 JSON のための表示グラマー

すべてのリーフは、保護された警告ポリシーを適用する前に、バリデーターの正確なレシートと構造化ダイジェストを検証します。

## 境界

<Warning>
  qxctl validate はファイルの修復、何かの公開、生の検出エビデンスの上書きを行うことはできません。警告の処理方法は表示に影響するものであり、検出には影響しません。
</Warning>

- 保護されたポリシー以外での警告の抑制は行わない
- バリデーター出力の変更は行わない
- 利用できないルートに対するカバレッジの捏造は行わない

## 一般的な用途

- 警告ベースラインを確立またはリセットする
- 管理対象の過去の警告を承認または再オープンする
- リポジトリの README に表示される、レシートに裏付けられたルートサマリーを出力する

このグラマーの基盤となるバリデーターは、コントラクトの形状、現在のソースの閉包、不変条件の所有権、機能管理、リリース、およびマシンが所有するルートサマリーをチェックします。
