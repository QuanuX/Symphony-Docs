アクティブなアプリケーションレベルの Symphony vector はそれぞれ、個別にインストール可能なプロセス外の C++ エンジンを持つことができます。権限を持たない共有 C++ メカニズムは `libraries/` の下にあり、独立した C++ コーディネーターが認証済みセッションとワークツリー調整のメカニズムを所有します。エンジンは、vector が所有するコントラクトの範囲内で検査、検証、プロジェクション、提案を行います。コンテンツを生成したというだけで権限を得ることはありません。

## SKV エンジンファミリー

SKV の各サーフェスには、それぞれ専用のエンジンがあります:

- SKVI、SCLV、SACV、SODV、SSFV の各エンジンは、inspect、check、propose、project (および該当する場合は recovery) を実装します。
- SAV と SEV のエンジンは、合成の評価と進化のケースのためのフリージングパスの C++26 プロセスです。

<Note>
  現在のすべての SKV エンジンは、読み取り、クエリ、検証、提案のみを行います。プログラムによる正規の適用は、各エンジンの SSIAG 権限検証、期待状態トランザクション、qxctl セーフガード、STAV イベント、リカバリー、ネガティブテストのコントラクトが完成するまで無効のままです。
</Note>

## 共通の保証

- モジュールごとの個別のインストールとアンインストール
- リポジトリの暗黙的なクロールはなく、マニフェストの検出は明示的
- 共有の権限はなく、すべての変更ルートは SSIAG と STAV によってゲートされる
- ホットパスへの常駐はなく、エンジンがライブワークロードにレイテンシーを持ち込むことはない
