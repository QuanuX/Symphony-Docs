## 新機能

- **Symphony Node Vector エンジン。** 個別にインストール可能な 5 つの C++26 エンジンが、Node のアイデンティティ (SNIV)、リソース (SNRV)、クラスター関係 (SCIV)、名前 (SCNV)、および SNV の合成と保持をカバーするようになりました。提供されたエビデンス、選択したビュー、保持された履歴を qxctl を通じて管理できます。ライブ観測と SOV プロビジョニングはまだ含まれていません。[Node Vector](/jp/vectors/snv) を参照してください。
- **オプションの SNV ローカルオブザーバー。** qxctl は、選択した CPU とメモリの観測値を明示的な不確実性とともに報告する、独立したローカルオブザーバーを呼び出せます。このオブザーバーがアイデンティティ、メンバーシップ、名前を割り当てることはありません。
- **SQV リサーチデータ基盤。** 新しい C++26 ライブラリが、元のバイト列とソースの来歴を伴うキャプチャ (SQAV)、メタデータ (SQMV)、フロー (SQFV)、系譜を伴う厳密な整数変換 (SQTV)、ローカル保持 (SQPV)、チェックポイントと厳密な再開を伴う配信 (SQDV) をカバーします。[Quantitative Vector](/jp/vectors/sqv) を参照してください。
- **qxctl による SQV 管理。** 個別にインストール可能な 7 つの管理エンジンが、リクエストと設定の検証、メタデータのプロジェクション、保持状態の読み取り専用検査を提供します。[Vector コマンド](/jp/qxctl/vector-commands) を参照してください。
- **Databento およびブローカーアダプター。** SQV は Databento DBNv3 MBO キャプチャをサポートし、DBNv1 および DBNv3 のサンプルを保持し、カバレッジのエビデンスを伴う範囲限定の履歴リクエストを計画できるようになりました。非ライブのソースおよびブローカー読み取りアダプターも利用可能です。認証済みのプロバイダー実行とライブ収集は今後の課題です。

## 更新

- **SSIAG のクレデンシャル受け入れ。** SSIAG に、ワンショットのクレデンシャル使用ガード、認証済みディスパッチの受け入れ、リカバリー機能付きの永続的なクレデンシャルリクエストジャーナル、macOS でのネイティブなピア検証が追加されました。運用上のクレデンシャル使用は無効のままです。[SSIAG](/jp/governance/ssiag) を参照してください。
- **qxctl のコマンドカバレッジ。** qxctl の安定したコマンドアイデンティティは 383 から 399 に増えました。エンジンバインディングは、5 つの SNV エンジンを含む 13 の確立されたロールをサポートします。[qxctl の概要](/jp/qxctl/overview) を参照してください。
- **SQFV バッチインターフェース。** SQFV バッチライブラリは、C ABI の代わりに C++26 API を使用するようになりました。以前のインターフェースを呼び出していた統合を更新してください。
- **SKVI の容量。** [SKVI](/jp/skv/skvi) は、新しい SQV リサーチデータのオーナーを含む、より多くのサーフェスをインデックス化します。
- **エンジンのインストールガイダンス。** インストールガイダンスで、各エンジンを個別にインストール、更新、削除することが明確になりました。[エンジンの概要](/jp/engines/overview) を参照してください。
