このリポジトリには、以前の QuanuX アプリケーション向けの Gemini CLI 拡張機能が含まれています。README では、GEMINI.md のコンテキストの読み込み、server/strategies への Python 戦略パッケージの生成、ランタイムエンジンのステータス確認について説明しています。

## ソースの評価 {#source-evaluation}

リポジトリには、Python の依存関係と、拡張機能を Gemini CLI にリンクする方法が記載されています。最新の README と依存関係ファイルを読み、拡張機能を確認したうえで、対応するアプリケーションのスナップショットを使って隔離されたワークスペースでテストしてください。

## Symphony との関係 {#relationship-to-symphony}

このプロジェクトは Symphony のネイティブなベータクライアントとは別物であり、署名済みの 0.2.0-beta.1 パッケージセットとの互換性を保証するものではありません。現在認定されている Symphony クライアントについては、[ベータ版のダウンロードとクライアント設定](https://quanux.org/downloads)を使用してください。レガシーアプリケーションのパスやコマンド例は、Symphony 全体の契約ではなく、このリポジトリに固有のものとして扱ってください。
