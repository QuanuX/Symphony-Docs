Dette repository indeholder en Gemini CLI-udvidelse til den tidligere QuanuX-applikation. Dens README beskriver indlæsning af GEMINI.md-kontekst, generering af Python-strategipakker i server/strategies og kontrol af runtime-motorens status.

## Vurdering af kildekoden {#source-evaluation}

Repositoryet beskriver Python-afhængigheder og sammenkædning af udvidelsen med Gemini CLI. Læs dets aktuelle README og afhængighedsfiler, gennemgå udvidelsen, og test den mod det tilsvarende applikationssnapshot i et isoleret arbejdsområde.

## Forhold til Symphony {#relationship-to-symphony}

Dette projekt er adskilt fra Symphonys native betaklient og fastslår ikke kompatibilitet med det signerede pakkesæt 0.2.0-beta.1. Brug [betadownloads og klientopsætning](https://quanux.org/downloads) til den aktuelle kvalificerede Symphony-klient. Betragt den ældre applikations stier og kommandoeksempler som tilhørende dette repository, ikke som universelle Symphony-kontrakter.
