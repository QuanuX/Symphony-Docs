Symphony er det open source-quantOS, der er udviklet efter Vector-Graph Application Architecture. Native motorer og SDK'er udfører domænearbejdet; qxctl giver agenter og mennesker en fælles kontrolflade. Brugerne vælger deres egne motorer, strategier, udbydere og topologi.

## Offentlig beta {#public-beta}

Den publicerede version er **0.2.0-beta.1**, lanceret den 16. november 2026. Den leverer 59 standardpakker pr. nøjagtig profil, en native Codex-klient, SDK-eksporter og valgfri tilsvarende kildekode.

| Mål | Arkitektur |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

Start med [downloads og Anaconda-vejledning](https://quanux.org/downloads), og brug derefter [vejledningen til betaens funktioner og test](https://quanux.org/beta).

## Funktioner at udforske {#capabilities-to-explore}

- qxctl-manifester, versioner, inspektion af installerede ejere og eksplicit administration.
- SQV-indsamling, metadata, flow, heltalskonvertering, lokale lagre, genafspilning og kontrolpunkter.
- SBV-forskning med afgrænsede backtests, census, native evaluering, bevarede resultater, annullering og gendannelse.
- SHV-hardwarekataloger med kildegrundlag, krav, grafer og forhåndsvisninger af publicering.
- SCV-udbyderviden samt SNV-identitet for Nodes, ressourcer, klyngerelationer og navngivning.
- SSIAG-autorisation, STAV-revisionsdokumentation, komposition og vidensgovernance.

## Kvalificeringsgrænser {#qualification-boundaries}

Versionsregistreringen identificerer de nøjagtige kvalificerede bytes. En fysisk DGX Spark, GPU-adfærd og live-udrulninger hos udbydere kræver separat dokumentation. Generel levering af legitimationsoplysninger og native udbyderbroer har eksplicitte implementeringshuller; installation af en adapter kvalificerer ikke en live-forbindelse. Rettelser på kildekodens hovedgren erstatter ikke signerede betaartefakter.

Læs den [aktuelle README og vedligeholdelsesnoterne for kildekoden](https://github.com/QuanuX/Symphony#readme) og specifikationen for hvert valgt modul, før du betjener det.
