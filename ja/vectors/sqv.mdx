Symphony Quantitative Vector（SQV）は、クオンツリサーチ、トレーディングシステムの構築、執行サポート、および将来のクオンツエンジンのための再利用可能なフレームワークコントラクトを所有します。戦略ロジックは常にあなたのものです。SQV はフレームワークのサーフェスと正確な互換性のエビデンスを提供しますが、銘柄、フィード、サブスクリプション、注文ロジック、執行モデルを決定することはありません。

## ユーザーの戦略の境界

戦略ロジックの所有権は完全にあなたにあります。SQV は次のことを行いません。

- 銘柄やデータフィードの選択
- サブスクリプションフィールドや板の深さの定義
- 障害時の動作や正規化ルールの決定
- 注文ロジックや執行モデルの作成
- 内部のモジュール構造の設計

Symphony は互換性のエビデンスとサポート対象の操作を提供します。戦略を順位付けしたり、トレーディングの判断にプラットフォームのルールを課したりすることはありません。

## SOOV: Symphony Orchestra Omega Vector

SOOV は SQV の下にある最初の名前付きサブベクトルです。これまでの QuanuX の取り組みを踏まえた、将来の高性能な C++ 専用 FIX アーキテクチャを表します。SOOV は、トレーディング通信のための範囲が限定された決定的なメッセージングレイヤーとして計画されています。FIX の詳細な動作はまだ正規化されておらず、FIX セッション、フィードアダプター、ブローカー統合は現在いずれも実装されていません。

## 将来のスコープ

SQV は、今後のデリバリーフェーズにわたって、承認済みのクオンツフレームワークコンポーネントの本拠地となる予定です。想定される領域は次のとおりです。

- バックテストエンジン
- ブローカーの C++ API
- インジケーターライブラリ
- クオンツ数学
- データストリームアーキテクチャ

これらはいずれも、それぞれのコントラクトが承認されるまで実装されません。

## 現在のステータス

SQV は正規のアーキテクチャコントラクトのみです。SQV や SOOV のエンジン、FIX セッション、フィードアダプター、戦略ランタイム、ブローカー統合、バックテスター、インジケーターライブラリ、データストリームコンポーネントは、現在いずれも実装されていません。
