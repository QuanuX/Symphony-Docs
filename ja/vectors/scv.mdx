Symphony Cloud Vector（SCV）は、オフサイトのハードウェアリソースと、クラスター、トレーニング、リサーチ、データ作業を形作るプロバイダーの実情に関するプライベートなセマンティック知識を所有します。プロバイダーを順位付けしたり、あなたが試みることに境界を課したりすることなく、プロバイダーのオファリング、リージョン、インフラストラクチャドメイン、制約、観測された可用性をマッピングします。

## プロバイダーのカバレッジ

SCV は次のプロバイダーとリソースタイプをカバーします。

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- ユーザー所有のハードウェア（オフサイトリソースとの比較が必要な場合）

## インストール済みエンジン

SCV の知識は、個別にインストール可能な 8 つの C++ エンジンを通じて提供されます。必要なものだけをインストールします。

## ポータブルなプロバイダーパッケージとコンポジション

SCV は qxctl を通じてポータブルなプロバイダーパッケージを公開します。要件、プロバイダーのパーミッション、レシピの代替案、実行の決定は、あなたが引き続き管理します。qxctl は保持されたワークフローと保護されたグラフ選択をサポートしているため、プロバイダーに再クエリすることなく正確なエビデンスをリプレイできます。

## オプションの DuckDB コネクター

`scv-graph-duckdb-connector` は、不変のネイティブグラフについて、範囲が限定されたリレーショナルプロジェクションを追加します。DuckDB はユーザーが選択したデフォルトの SQL データベースです。将来的には、追加のアダプターを通じて専用のグラフエンジンを選択できるようになる可能性があります。

## プライバシーと主権

インストールされた SCV の知識グラフは、あなたのプライベートなインストールに属します。ユーザーが提供するアカウント、残高、パーミッション、契約上の制約は、明示的に有効化された観測サーフェスを通じてのみ使用されます。プライベートな事実が Symphony の公式なソースの真実に入ることはありません。

## バージョン管理されたインターフェースの増分

SCV のリリースは追加的で、厳密にバージョン管理されています。以前のインストールは、その正確なスコープで引き続き呼び出し可能です。現在の増分には、ネイティブ操作、コーパススナップショット、解釈プロファイル、ポータブルなプロバイダーパック、コンポジションワークフロー、義務の追跡、エビデンスバンドルが含まれます。各増分は、以前のルート、デフォルト、レコードを保持します。
