アクティブなアプリケーションレベルの Symphony ベクターはそれぞれ、個別にインストール可能なプロセス外の C++ エンジンを持つことができます。権限を持たない共有の C++ メカニズムは `libraries/` の下にあり、別個の C++ コーディネーターが認証済みセッションとワークツリー調整のメカニズムを担います。エンジンは、ベクターが所有するコントラクトの範囲内で検査、検証、プロジェクション、提案を行います。コンテンツを生成したというだけで権限を得ることはありません。

## SKV エンジンファミリー

SKV の各サーフェスには、それぞれ独自のエンジンがあります。

- SKVI、SCLV、SACV、SODV、SSFV の各エンジンは、inspect、check、propose、project（および該当する場合は recovery）を実装します。
- SAV と SEV のエンジンは、合成の評価と進化のケースを扱うフリージングパスの C++26 プロセスです。

<Note>
  現在のすべての SKV エンジンは、読み取り、クエリ、検証、提案のみを行います。プログラムによる正規の適用は、各エンジンの SSIAG 権限検証、期待状態トランザクション、qxctl セーフガード、STAV イベント、リカバリー、ネガティブテストのコントラクトが完成するまで無効のままです。
</Note>

## 共通の保証

- モジュールごとに個別にインストールおよびアンインストール可能
- リポジトリの暗黙的なクロールは行わず、マニフェストの検出は明示的
- 共有された権限はなく、変更を伴うすべてのルートは SSIAG と STAV によって制御される
- ホットパスに常駐せず、エンジンがライブワークロードにレイテンシーを持ち込むことはない
