`qxctl knowledge engines ...` グラマーは、Symphony のベクトルエンジン向けの保護されたユーザースコープ `default` バインディングプロファイルを管理します。選択したコンテンツを後の reconciliation のためにバインドします。エンジンのインストール、呼び出し、有効化、ドッキング、認証、認可、apply は行いません。

## コマンド

```bash Engines grammar
qxctl knowledge engines list
qxctl knowledge engines inspect
qxctl knowledge engines doctor
qxctl knowledge engines bind    --expected-registry-digest absent|DIGEST ...
qxctl knowledge engines unbind  --expected-registry-digest DIGEST ...
qxctl knowledge engines migrate --expected-registry-digest DIGEST ...
```

最初の v2 レジストリ変更には `absent` を指定し、以降の変更には `list` が報告する正確なダイジェストを指定します。すべての変更は、そのダイジェストに対する compare-and-swap です。

## v1 から v2 への移行

<Warning>
  有効な v1 レジストリ状態は引き続き読み取り可能です。v2 への移行は独立した厳密な compare-and-swap であり、バージョン選択操作になることはありません。移行をエンジン選択のアップグレードパスとして扱わないでください。
</Warning>

- `list` と `inspect` は v1 のエビデンスに対しても引き続き動作します。
- `migrate` は v1 の真実を破棄することなく、リンクされた v2 世代を生成します。
- 移行後は、以降の変更に v2 のダイジェストを使用します。

## bind とは

bind は、コーディネーターによる後の reconciliation のために正確なコンテンツを選択します。bind は次のことを行いません。

- エンジンをインストールしない
- エンジンを呼び出したり有効化したりしない
- エンジンを Maestro にドッキングしない
- 呼び出し元を認証しない
- apply を認可しない
