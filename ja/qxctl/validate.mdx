`qxctl validate ...` グラマーは、Symphony Validator の保護された警告ポリシー、ベースライン、表示グラマーを管理します。独立してインストールされる C++ バリデーターが不変の生エビデンスを生成し、qxctl は検出を変更することなく、呼び出し元に中立な保護された表示を管理します。

## qxctl validate がカバーする範囲

- 9 つの保護された警告ライフサイクルリーフ
- 正確なレシートに裏付けられたルートサマリールート
- ベースライン管理と差分レポート
- 行出力と構造化 JSON の表示グラマー

すべてのリーフは、保護された警告ポリシーを適用する前に、バリデーターの正確なレシートと構造化ダイジェストを検証します。

## 境界

<Warning>
  qxctl validate は、ファイルの修復、何かの公開、生の検出エビデンスの上書きを行うことはできません。警告の処理は表示に影響するものであり、検出には影響しません。
</Warning>

- 保護されたポリシー外での警告抑制は行わない
- バリデーター出力の変更は行わない
- 利用できないルートに対するカバレッジの捏造は行わない

## 一般的な用途

- 警告ベースラインの確立またはリセット
- 管理対象の過去の警告の承認または再オープン
- リポジトリの README に表示される、レシートに裏付けられたルートサマリーの出力

このグラマーを支えるバリデーターは、コントラクトの形状、現在のソースクロージャー、不変条件の所有権、機能管理、リリース、およびマシンが所有するルートサマリーをチェックします。
