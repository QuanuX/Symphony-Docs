Symphony Validator（`tools/symphony-validator`）は、独立した、決定論的で読み取り専用の C++26 リポジトリチェッカーです。リポジトリとそのコントラクトの現在の状態について、不変のエビデンスを生成します。何かを修復したり公開したりすることはできません。

## Validator がチェックするもの

- コントラクトの形式: 必須の Contract Quad のアンカーと構造
- SKVI でインデックス化されたサーフェス全体にわたる、現在のソースの閉包
- `knowledge/INVARIANTS.md` と不変条件レジストリに基づく不変条件の所有権
- SSFV が報告する機能管理の期待値
- SODV が報告するリリースレコード
- リポジトリの README にある、機械が所有するルートサマリー

エビデンスは行形式の出力または構造化 JSON として出力されます。すべての出力は、同じリポジトリの状態から再現可能です。

## Validator が行わないこと

<Warning>
  Validator は、ファイルの修復、コントラクトの書き換え、リポジトリの公開を行うことはできません。正規の真実を何ひとつ作り出すことはなく、報告するだけです。
</Warning>

- リポジトリへの副作用はない
- ネットワークアクセスはない
- qxctl の保護された警告ポリシー以外で警告を抑制することはない

## qxctl との統合

qxctl は、保護された警告ポリシーを適用する前に、Validator の正確なレシートと構造化されたダイジェストを検証します。保護された 9 つの警告ライフサイクル用 qxctl リーフと、レシートに裏付けられた正確なルートサマリーのルートにより、生の検出結果のエビデンスを変更することなく検証の管理機能が提供されます。
