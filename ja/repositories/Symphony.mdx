Symphony は、Vector-Graph Application Architecture によって開発されたオープンソースの quantOS です。ネイティブのエンジンと SDK がドメインの処理を担い、qxctl はエージェントと人に共通の制御サーフェスを提供します。エンジン、戦略、プロバイダー、トポロジーはユーザー自身が選択します。

## 公開ベータ版 {#public-beta}

公開されたリリースは、2026年11月16日にリリースされた **0.2.0-beta.1** です。正確なプロファイルごとに 59 個のデフォルトパッケージ、ネイティブの Codex クライアント、SDK のエクスポート、オプションの対応ソースを提供します。

| ターゲット | アーキテクチャ |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

まず[ダウンロードと Anaconda の手順](https://quanux.org/downloads)から始め、その後[ベータ版の機能とテストのガイド](https://quanux.org/beta)を参照してください。

## 試せる機能 {#capabilities-to-explore}

- qxctl のマニフェスト、バージョン、インストール済みオーナーの確認、明示的な管理。
- SQV のキャプチャ、メタデータ、フロー、整数変換、ローカルストア、リプレイ、チェックポイント。
- SBV の範囲を限定したバックテストリサーチ、センサス、ネイティブ評価、保持された結果、キャンセル、復旧。
- SHV のソースに基づくハードウェアカタログ、要件、グラフ、公開プレビュー。
- SCV のプロバイダー知識と、SNV の Node アイデンティティ、リソース、クラスター関係、命名。
- SSIAG の認可、STAV の監査証拠、コンポジション、ナレッジガバナンス。

## 認定の境界 {#qualification-boundaries}

リリース記録は、認定された正確なバイトを特定します。物理的な DGX Spark、GPU の動作、ライブプロバイダーへのデプロイメントには、別途証拠が必要です。一般的な認証情報の配布とネイティブのプロバイダーブリッジには、明示された実装上のギャップがあります。アダプターをインストールしても、ライブ接続が認定されるわけではありません。ソースのメインブランチでの修正は、署名済みのベータ版成果物に代わるものではありません。

選択した各モジュールを運用する前に、[最新のソース README とメンテナンスノート](https://github.com/QuanuX/Symphony#readme)、およびそのモジュールの仕様をお読みください。
