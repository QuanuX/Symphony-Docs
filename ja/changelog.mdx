## 新機能

- **Symphony Node Vector エンジン。** 個別にインストール可能な 5 つの C++26 エンジンが、Node のアイデンティティ（SNIV）、リソース（SNRV）、クラスター関係（SCIV）、名前（SCNV）、および SNV の合成と保持をカバーするようになりました。提供されたエビデンス、選択したビュー、保持された履歴を qxctl から管理できます。ライブ観測と SOV プロビジョニングはまだ含まれていません。詳しくは [Node Vector](/ja/vectors/snv) を参照してください。
- **オプションの SNV ローカルオブザーバー。** qxctl は独立したローカルオブザーバーを呼び出すことができ、このオブザーバーは選択された CPU とメモリの観測結果を明示的な不確実性とともに報告します。アイデンティティ、メンバーシップ、名前を割り当てることはありません。
- **SQV 研究データ基盤。** 新しい C++26 ライブラリが、元のバイト列とソースの来歴を保持したキャプチャ（SQAV）、メタデータ（SQMV）、フロー（SQFV）、系譜付きの正確な整数変換（SQTV）、ローカル保持（SQPV）、チェックポイントと正確な再開を備えた配信（SQDV）をカバーします。詳しくは [Quantitative Vector](/ja/vectors/sqv) を参照してください。
- **qxctl による SQV 管理。** 個別にインストール可能な 7 つの管理エンジンが、リクエストと構成の検証、メタデータのプロジェクション、保持された状態の読み取り専用検査を提供します。詳しくは [Vector コマンド](/ja/qxctl/vector-commands) を参照してください。
- **Databento およびブローカーアダプター。** SQV は Databento DBNv3 MBO キャプチャをサポートし、DBNv1 と DBNv3 のサンプルを保持し、カバレッジのエビデンスとともに範囲を限定した履歴リクエストを計画するようになりました。非ライブのソースおよびブローカー読み取りアダプターも利用できます。認証済みのプロバイダー実行とライブ収集は今後の作業です。

## アップデート

- **SSIAG クレデンシャルの受け入れ。** SSIAG に、ワンショットのクレデンシャル使用ガード、認証済みディスパッチの受け入れ、リカバリー機能付きの永続的なクレデンシャルリクエストジャーナル、macOS でのネイティブなピア検証が追加されました。運用上のクレデンシャル使用は引き続き無効です。詳しくは [SSIAG](/ja/governance/ssiag) を参照してください。
- **qxctl コマンドのカバレッジ。** qxctl の安定したコマンドアイデンティティは 383 から 399 に増えました。エンジンバインディングは、5 つの SNV エンジンを含む 13 の確立されたロールをサポートします。詳しくは [qxctl の概要](/ja/qxctl/overview) を参照してください。
- **SQFV バッチインターフェース。** SQFV バッチライブラリは C ABI ではなく C++26 API を使用するようになりました。以前のインターフェースを呼び出していた統合はすべて更新してください。
- **SKVI の容量。** [SKVI](/ja/skv/skvi) は、新しい SQV 研究データのオーナーを含む、より多くのサーフェスをインデックスするようになりました。
- **エンジンのインストールガイダンス。** インストールガイダンスで、各エンジンを個別にインストール、更新、削除することが明確になりました。詳しくは [エンジンの概要](/ja/engines/overview) を参照してください。
