O grupo `qxctl knowledge ...` é responsável pelo ciclo de vida entre vetores e pela administração persistente de sessões SSFV. É o ponto de entrada para operações suportadas pelo coordenador e para consultas de invariantes ao validador.

## Transição de sessão

Utilize `qxctl knowledge session transition` para sinalizar um evento de ciclo de vida do anfitrião a uma sessão existente:

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

As novas tentativas seguras reutilizam o mesmo ID de evento. Adicione `--recover` apenas quando se pretende uma recuperação por descoberta a partir de evidência de sessão local danificada; não recupera recusas, estados críticos incompatíveis nem ambiguidades.

<Warning>
  O Symphony não instala um hook de início de sessão, um watcher nem uma unidade de arranque através deste comando. Utilize-o apenas quando uma integração explícita com o ciclo de vida do anfitrião fornecer uma identidade de evento estável.
</Warning>

## Consultas de invariantes

Quatro folhas associam `ssfv:symphony:qxctl.invariant-assurance`:

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` associa adicionalmente `ssfv:symphony:symphony-validator.invariant-ownership-assurance`.

As folhas de consulta direta emitem `symphony.knowledge.invariant-query-result.v1` com `semantic_validity=not_asserted`. `check` devolve o resultado exato e completo do validador e preserva o código de saída 26.
