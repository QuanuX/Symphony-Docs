Este repositório público contém um snapshot anterior do aplicação quantitativa QuanuX, com uma meta de pré-lançamento v0.0.1-pre. O respetivo README descreve um servidor Python, ferramentas de cliente com Node/pnpm e um caminho de desenvolvimento desktop com Tauri.

## Mantenha as versões separadas {#keep-the-releases-distinct}

O pacote Conda quanux anterior e as instruções de configuração da aplicação pertencem a este snapshot. Não são o caminho de instalação do Symphony Public Beta 0.2.0-beta.1.

Para a versão nativa atual do Symphony, use [os downloads do Symphony e os perfis exatos do Anaconda](https://quanux.org/downloads) e [o guia de testes da beta](https://quanux.org/beta).

## Explore o snapshot {#explore-the-snapshot}

Use o README, a licença, os manifestos de dependências e a revisão de código-fonte registrada deste repositório ao investigar a arquitetura ou reproduzir o comportamento histórico. As APIs experimentais e o respetivo modelo de aplicação não devem ser promovidos silenciosamente para a arquitetura atual do Symphony nem para afirmações de prontidão.
