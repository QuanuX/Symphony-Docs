Este projeto fornece superfícies nativas de IPC local e MCP para o Antigravity e outros fluxos de trabalho de clientes de agentes, com suporte a CLI e configuração de ligação explícita.

## O que avaliar {#what-to-evaluate}

- Reveja os requisitos de compilação C++26 declarados e o contrato do protocolo.
- Inspecione as opções de transporte stdio e IPC local e os respetivos limites de autoridade.
- Gere e reveja uma configuração de cliente para o host pretendido.
- Execute os testes do repositório antes de avaliar uma sessão real de cliente de agente.

As integrações do Antigravity, agy, Gemini, Codex e Claude mantêm requisitos de configuração e qualificação específicos de cada cliente. Este repositório independente é diferente do cliente Codex incluído na distribuição assinada do Symphony. Não deduza a inclusão na beta binária nem a aprovação em diretórios de terceiros a partir da disponibilidade do código-fonte.
