Este repositório contém uma extensão do Gemini CLI para o aplicação QuanuX anterior. O respetivo README descreve como carregar o contexto do GEMINI.md, gerar pacotes de estratégias em Python em server/strategies e verificar o estado do motor de runtime.

## Avaliação do código-fonte {#source-evaluation}

O repositório descreve as dependências Python e como associar a extensão ao Gemini CLI. Leia o README e os ficheiros de dependências atuais, reveja a extensão e teste-a com o snapshot correspondente da aplicação num espaço de trabalho isolado.

## Relação com o Symphony {#relationship-to-symphony}

Este projeto é diferente do cliente beta nativo do Symphony e não estabelece compatibilidade com o conjunto de pacotes assinado 0.2.0-beta.1. Para o cliente Symphony qualificado atual, use [os downloads da beta e a configuração do cliente](https://quanux.org/downloads). Trate os caminhos da aplicação legado e os exemplos de comandos como pertencentes a este repositório, e não como contratos universais do Symphony.
