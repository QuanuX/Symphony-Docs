Symphony API Contract Vector (SACV) पूरे प्लेटफ़ॉर्म पर संस्करणित API कॉन्ट्रैक्ट्स को शासित करता है। इसका इंजन एक स्वतंत्र रूप से इंस्टॉल किया जा सकने वाला C++ प्रोसेस है जो सीमित OpenAPI 3.2.0 JSON सत्यापन, नियतात्मक संगतता डिफ़ और डिस्पोज़ेबल इन्वेंटरी करता है। एंडपॉइंट सिमेंटिक्स डोमेन-स्वामी वेक्टर या मॉड्यूल के पास रहते हैं; SACV कॉन्ट्रैक्ट के आकार और संगतता को शासित करता है।

## ऑपरेशन

- **Inspect और check**: सत्यापित करें कि कोई OpenAPI 3.2.0 JSON दस्तावेज़ सीमित प्रोफ़ाइल के अनुरूप है।
- **Diff**: कॉन्ट्रैक्ट संस्करणों के बीच नियतात्मक संगतता डिफ़ की गणना करें।
- **Propose**: नए या बदले गए कॉन्ट्रैक्ट्स के लिए कॉलर-घोषित रजिस्ट्री प्रस्ताव स्वीकार करें।
- **Project**: समीक्षकों और डाउनस्ट्रीम टूल्स के लिए डिस्पोज़ेबल इन्वेंटरी उत्सर्जित करें।

## SACV क्या शासित करता है

SACV निम्न को सीमित करता है:

- कॉन्ट्रैक्ट का आकार (SACV प्रोफ़ाइल के साथ OpenAPI 3.2.0)
- संस्करणों के बीच संगतता वर्गीकरण
- स्वीकृत कॉन्ट्रैक्ट्स के लिए रजिस्ट्री सदस्यता

यह निम्न नहीं करता:

- एंडपॉइंट सिमेंटिक्स का स्वामित्व (हर वेक्टर या मॉड्यूल उन्हें अपने पास रखता है)
- SDK जनरेट करना, आर्टिफ़ैक्ट प्रकाशित करना या टोकन जारी करना
- यह संकेत देना कि कोई लाइव नेटवर्क सतह मौजूद है (भविष्य के किसी निजी API का उल्लेख उसे बनाता नहीं है)

<Note>
  SACV केवल read, query, validate और propose करता है। SKV इंजनों में प्रोग्रामेटिक कैनॉनिकल apply निष्क्रिय है।
</Note>
