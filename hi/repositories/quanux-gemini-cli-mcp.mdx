इस रिपॉज़िटरी में पुराने QuanuX ऐप्लिकेशन के लिए एक Gemini CLI एक्सटेंशन है। इसका README GEMINI.md कॉन्टेक्स्ट लोड करने, server/strategies में Python स्ट्रैटेजी पैकेज जनरेट करने और रनटाइम इंजन की स्थिति जाँचने का वर्णन करता है।

## सोर्स मूल्यांकन {#source-evaluation}

रिपॉज़िटरी Python डिपेंडेंसी और एक्सटेंशन को Gemini CLI से लिंक करने का वर्णन करती है। इसका वर्तमान README और डिपेंडेंसी फ़ाइलें पढ़ें, एक्सटेंशन की समीक्षा करें, और एक अलग वर्कस्पेस में मेल खाने वाले ऐप्लिकेशन स्नैपशॉट के साथ इसे टेस्ट करें।

## Symphony से संबंध {#relationship-to-symphony}

यह प्रोजेक्ट Symphony के नेटिव बीटा क्लाइंट से अलग है और हस्ताक्षरित 0.2.0-beta.1 पैकेज सेट के साथ संगतता स्थापित नहीं करता। वर्तमान क्वालिफ़ाइड Symphony क्लाइंट के लिए [बीटा डाउनलोड और क्लाइंट सेटअप](https://quanux.org/downloads) का उपयोग करें। पुराने ऐप्लिकेशन के पाथ और कमांड उदाहरणों को सार्वभौमिक Symphony कॉन्ट्रैक्ट नहीं, बल्कि इस रिपॉज़िटरी से संबंधित मानें।
