Symphony Quantitative Vector (SQV) володіє повторно використовуваними контрактами фреймворку для кількісних досліджень, побудови торгових систем, підтримки виконання та майбутніх кількісних рушіїв. Логіка стратегій завжди належить вам. SQV надає поверхні фреймворку та точні докази сумісності, але ніколи не визначає ваші інструменти, канали даних, підписки, логіку ордерів чи модель виконання.

## Межа стратегій користувача

Ви зберігаєте повне володіння логікою стратегій. SQV не:

- Обирає ваші інструменти чи канали даних
- Визначає поля підписки чи глибину ринку
- Визначає поведінку при збоях чи правила нормалізації
- Пише логіку ордерів чи моделі виконання
- Проєктує вашу внутрішню модульну структуру

Symphony надає докази сумісності та підтримувані операції. Він ніколи не ранжує стратегії й не нав’язує правила платформи вашим торговим рішенням.

## SOOV: Symphony Orchestra Omega Vector

SOOV — перший іменований підвектор у складі SQV. Він представляє майбутню високопродуктивну FIX-архітектуру виключно на C++, що спирається на історичні напрацювання QuanuX. SOOV планується як обмежений детермінований рівень обміну повідомленнями для торгової комунікації. Детальна поведінка FIX ще не є канонічною; наразі не реалізовано жодної FIX-сесії, адаптера каналу даних чи інтеграції з брокером.

## Майбутній обсяг

SQV — запланований дім для ратифікованих компонентів кількісного фреймворку на пізніших етапах постачання. Очікувані напрями включають:

- Рушії бектестингу
- C++ API брокерів
- Бібліотеки індикаторів
- Кількісну математику
- Архітектуру потоків даних

Жоден із них не буде реалізовано, доки не ратифіковано відповідні контракти.

## Поточний статус

SQV — це лише канонічний архітектурний контракт. Наразі не реалізовано жодного рушія SQV чи SOOV, FIX-сесії, адаптера каналу даних, середовища виконання стратегій, інтеграції з брокером, бектестера, бібліотеки індикаторів чи компонента потоків даних.
