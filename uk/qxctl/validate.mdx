Граматика `qxctl validate ...` адмініструє захищену політику попереджень, базову лінію та граматику відображення Symphony Validator. Незалежно встановлений валідатор на C++ створює незмінні сирі докази; qxctl адмініструє нейтральне щодо викликача захищене подання, не змінюючи виявлення.

## Що охоплює qxctl validate

- Дев’ять захищених листових команд життєвого циклу попереджень
- Точний маршрут кореневого підсумку, підкріплений квитанцією
- Керування базовою лінією та звіти про відмінності
- Граматику відображення для рядкового виводу та структурованого JSON

Кожна листова команда перевіряє точну квитанцію валідатора та структуровані дайджести, перш ніж застосувати захищену політику попереджень.

## Межа

<Warning>
  qxctl validate не може виправляти файли, щось публікувати чи перевизначати сирі докази детектора. Розпорядження попередженнями впливає на подання, а не на виявлення.
</Warning>

- Жодного придушення попереджень поза захищеною політикою
- Жодної модифікації виводу валідатора
- Жодного вигаданого покриття для недоступного маршруту

## Типові випадки використання

- Встановити або скинути базову лінію попереджень
- Схвалити або повторно відкрити кероване історичне попередження
- Видати підкріплений квитанцією кореневий підсумок, що відображається в README репозиторію

Валідатор, на якому ґрунтується ця граматика, перевіряє форму контрактів, поточне замикання вихідного коду, володіння інваріантами, адміністрування функцій, випуски та машинно-керований кореневий підсумок.
