Symphony API Contract Vector (SACV) керує версіонованими контрактами API в усій платформі. Його рушій — це незалежно встановлюваний процес на C++, що виконує обмежену валідацію JSON за OpenAPI 3.2.0, детерміновані порівняння сумісності та створює одноразові інвентарі. Семантика кінцевих точок залишається за вектором чи модулем, що володіє доменом; SACV керує формою контрактів і сумісністю.

## Операції

- **Inspect і check**: перевірка відповідності JSON-документа OpenAPI 3.2.0 обмеженому профілю.
- **Diff**: обчислення детермінованих порівнянь сумісності між версіями контрактів.
- **Propose**: прийняття заявлених викликачем пропозицій до реєстру для нових або змінених контрактів.
- **Project**: створення одноразових інвентарів для рецензентів і подальших інструментів.

## Чим керує SACV

SACV обмежує:

- Форму контракту (OpenAPI 3.2.0 із профілем SACV)
- Класифікацію сумісності між версіями
- Членство в реєстрі для прийнятих контрактів

Він не:

- Володіє семантикою кінцевих точок (вона залишається за кожним вектором чи модулем)
- Генерує SDK, не публікує артефакти й не видає токени
- Передбачає існування живої мережевої поверхні (згадка про майбутній приватний API не створює її)

<Note>
  SACV лише читає, виконує запити, перевіряє й пропонує. Програмне канонічне застосування вимкнено для всіх рушіїв SKV.
</Note>
