Цей репозиторій відповідає за дистрибуцію та докази випуску Symphony. Публічну бета-версію **0.2.0-beta.1** опубліковано 16 листопада 2026 р.

## Завантаження та встановлення {#download-and-install}

Використовуйте [quanux.org/downloads](https://quanux.org/downloads), щоб отримати інсталятори для платформ, інструкції щодо Anaconda та описи всіх пакетів. [Сторінка випуску](https://github.com/QuanuX/symphony-distribution/releases/tag/v0.2.0-beta.1) визначає точні артефакти.

Профілі: macOS 15 ARM64, Ubuntu 24.04 AMD64, Ubuntu 24.04 ARM64 і Ubuntu 26.04 AMD64. Кожен містить 59 незалежно підтримуваних пакетів за замовчуванням і необов'язковий відповідний вихідний код. Когорти Linux AMD64 мають спільний підкаталог Conda, але є різними кваліфікованими збірками: використовуйте явний список точного профілю.

## Перевірка та перше використання {#verification-and-first-use}

1. Прочитайте [посібник зі встановлення](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md).
2. Перевірте підписаний маніфест, індекс випуску та вибрані файли закріпленим засобом перевірки.
3. Установіть у новий приватний префікс від імені звичайного користувача.
4. Збережіть перевірені бінарні файли в окремому приватному каталозі зберігання.
5. Перегляньте згенеровану конфігурацію клієнта та явно виберіть нативних власників і повноваження.

Conda 26.10.0 пройшла кваліфікацію. Для перевірки й налаштування потрібні Python 3.11+ і OpenSSL; компілятор для запуску наданих бінарних файлів не потрібен. Пакет PKG для Mac не підписано Apple Developer ID і не нотаризовано. Від'єднана перевірка не змінює довіру системи.

## Докази життєвого циклу {#lifecycle-evidence}

Випуск кваліфікує шляхи встановлення та першого використання, 22 сценарії Codex і 182 транзакції обслуговування пакетів на профіль. Ревізія 0 → 1 → 0 використовує ідентичні нативні байти. Оновлення до інших нативних версій, збережені копії та життєві цикли запущених власників залишаються окремими. Див. [посібник зі збереження](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/RETENTION.md).
