Цей репозиторій містить розширення Gemini CLI для попереднього застосунку QuanuX. Його README описує завантаження контексту GEMINI.md, генерування пакетів стратегій на Python у server/strategies і перевірку стану рушія середовища виконання.

## Оцінювання вихідного коду {#source-evaluation}

У репозиторії описано залежності Python і підключення розширення до Gemini CLI. Прочитайте його актуальний README і файли залежностей, перегляньте розширення та протестуйте його з відповідним знімком застосунку в ізольованому робочому просторі.

## Зв'язок із Symphony {#relationship-to-symphony}

Цей проєкт відрізняється від нативного бета-клієнта Symphony і не встановлює сумісності з підписаним набором пакетів 0.2.0-beta.1. Для поточного кваліфікованого клієнта Symphony використовуйте [завантаження бета-версії та налаштування клієнта](https://quanux.org/downloads). Розглядайте шляхи застарілого застосунку та приклади команд як такі, що належать цьому репозиторію, а не як універсальні контракти Symphony.
