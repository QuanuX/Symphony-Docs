每个处于活动状态的应用级 Symphony vector 都可以拥有一个可独立安装、在进程外运行的 C++ 引擎。共享的无权限 C++ 机制位于 `libraries/` 下；一个单独的 C++ 协调器负责经过身份验证的会话和工作树协调机制。引擎在 vector 拥有的契约范围内进行检查、验证、投影和提议。它们不会仅仅因为生成了内容就获得权限。

## SKV 引擎系列

每个 SKV 表面都有自己的引擎：

- SKVI、SCLV、SACV、SODV 和 SSFV 引擎各自实现检查、校验、提议、投影（以及适用时的恢复）。
- SAV 和 SEV 引擎是冻结路径的 C++26 进程，分别用于组合评估和演进案例。

<Note>
  当前所有 SKV 引擎都仅支持读取、查询、验证和提议。在每个引擎的 SSIAG 权限验证、预期状态事务、qxctl 安全措施、STAV 事件、恢复以及负面测试契约全部完成之前，程序化的规范应用将保持禁用。
</Note>

## 通用保证

- 每个模块独立安装和卸载
- 不进行环境式仓库爬取；清单发现是显式的
- 没有共享权限；每条变更路由都由 SSIAG 加 STAV 把关
- 不在热路径上常驻；引擎绝不会给实时工作负载引入延迟
