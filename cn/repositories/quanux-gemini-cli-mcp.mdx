该仓库包含一个用于早期 QuanuX 应用的 Gemini CLI 扩展。其 README 介绍了如何加载 GEMINI.md 上下文、在 server/strategies 中生成 Python 策略包，以及检查运行时引擎状态。

## 源代码评估 {#source-evaluation}

该仓库介绍了 Python 依赖项以及如何将扩展与 Gemini CLI 关联。请阅读其当前 README 和依赖文件，审阅该扩展，并在隔离的工作区中使用对应的应用快照进行测试。

## 与 Symphony 的关系 {#relationship-to-symphony}

该项目与 Symphony 的原生测试版客户端不同，并不保证与已签名的 0.2.0-beta.1 软件包集兼容。如需当前经过认证的 Symphony 客户端，请使用[测试版下载和客户端设置](https://quanux.org/downloads)。请将旧版应用的路径和命令示例视为本仓库特有的内容，而不是通用的 Symphony 契约。
