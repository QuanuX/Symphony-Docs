该项目为 Antigravity 及其他智能体客户端工作流提供原生本地 IPC 和 MCP 接口，并支持 CLI 和显式的连接配置。

## 需要评估的内容 {#what-to-evaluate}

- 查看声明的 C++26 构建要求和协议契约。
- 检查 stdio 与本地 IPC 传输方式及其权限边界。
- 为目标主机生成并审阅客户端配置。
- 在评估真实的智能体客户端会话之前，先运行仓库中的测试。

Antigravity、agy、Gemini、Codex 和 Claude 集成各自保留其特定于客户端的配置和资格认证要求。这个独立仓库与签名版 Symphony 发行版中附带的 Codex 客户端不同。不要因为源代码公开可用，就推断它已包含在二进制测试版中，或已在第三方目录中获得批准。
