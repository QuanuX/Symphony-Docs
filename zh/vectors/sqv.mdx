Symphony Quantitative Vector（SQV，Symphony 量化向量）拥有可复用的框架契约，涵盖量化研究、交易系统构建、执行支持以及后续的量化引擎。策略逻辑始终归你所有。SQV 提供框架接口和精确的兼容性证据，但绝不决定你的交易品种、数据源、订阅、订单逻辑或执行模型。

## 用户策略边界

你对策略逻辑保留完整的所有权。SQV 不会：

- 选择你的交易品种或数据源
- 定义订阅字段或市场深度
- 决定故障行为或规范化规则
- 编写订单逻辑或执行模型
- 设计你的内部模块化结构

Symphony 提供兼容性证据和受支持的操作。它绝不会对策略进行排名，也不会对你的交易决策强加平台规则。

## SOOV：Symphony Orchestra Omega Vector

SOOV 是 SQV 下首个已命名的子向量。它代表一种借鉴 QuanuX 历史工作的未来高性能、纯 C++ 的 FIX 架构。SOOV 计划作为一个有界、确定性的交易通信消息层。详细的 FIX 行为尚未成为规范；目前尚未实现任何 FIX 会话、数据源适配器或经纪商集成。

## 未来范围

SQV 计划作为后续交付阶段中已批准的量化框架组件的归属。预期领域包括：

- 回测引擎
- 经纪商 C++ API
- 指标库
- 量化数学
- 数据流架构

在各自的契约获得批准之前，以上内容均不会实现。

## 当前状态

SQV 目前仅是一份规范架构契约。目前尚未实现任何 SQV 或 SOOV 引擎、FIX 会话、数据源适配器、策略运行时、经纪商集成、回测器、指标库或数据流组件。
