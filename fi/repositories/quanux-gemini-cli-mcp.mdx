Tämä repositorio sisältää Gemini CLI -laajennuksen aiempaa QuanuX-sovellusta varten. Sen README kuvaa GEMINI.md-kontekstin lataamisen, Python-strategiapakettien luomisen hakemistoon server/strategies ja ajonaikaisen moottorin tilan tarkistamisen.

## Lähdekoodin arviointi {#source-evaluation}

Repositorio kuvaa Python-riippuvuudet ja laajennuksen linkittämisen Gemini CLI:hin. Lue sen nykyinen README ja riippuvuustiedostot, tarkista laajennus ja testaa sitä vastaavaa sovelluksen tilannevedosta vasten eristetyssä työtilassa.

## Suhde Symphonyyn {#relationship-to-symphony}

Tämä projekti on erillinen Symphonyn natiivista beta-asiakkaasta, eikä se osoita yhteensopivuutta allekirjoitetun 0.2.0-beta.1-pakettijoukon kanssa. Käytä nykyiselle kelpuutetulle Symphony-asiakkaalle [betan latauksia ja asiakkaan määritystä](https://quanux.org/downloads). Käsittele vanhan sovelluksen polkuja ja komentoesimerkkejä tämän repositorion omina, ei yleisinä Symphony-sopimuksina.
