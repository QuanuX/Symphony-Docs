`qxctl knowledge ...` -ryhmä vastaa vektorien välisestä elinkaaresta ja pysyvien SSFV-istuntojen hallinnasta. Se on lähtökohta koordinaattorin tukemille operaatioille ja validaattoriin kohdistuville invarianttikyselyille.

## Istunnon siirtymä

Käytä komentoa `qxctl knowledge session transition` ilmoittaaksesi isännän elinkaaritapahtumasta olemassa olevalle istunnolle:

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

Turvalliset uudelleenyritykset käyttävät samaa tapahtumatunnistetta. Lisää `--recover` vain, kun tarkoituksena on löytöpalautus vahingoittuneista paikallisista istuntotodisteista; se ei palauta epäämistä, yhteensopimatonta kriittistä tilaa eikä monitulkintaisuutta.

<Warning>
  Symphony ei asenna tämän komennon kautta kirjautumiskoukkua, valvojaa eikä käynnistysyksikköä. Käytä sitä vain, kun eksplisiittinen isännän elinkaari-integraatio tarjoaa vakaan tapahtumaidentiteetin.
</Warning>

## Invarianttikyselyt

Neljä lehtikomentoa sitoo `ssfv:symphony:qxctl.invariant-assurance`:

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` sitoo lisäksi `ssfv:symphony:symphony-validator.invariant-ownership-assurance`.

Suorat kyselylehdet tuottavat `symphony.knowledge.invariant-query-result.v1` -tuloksen, jossa `semantic_validity=not_asserted`. `check` palauttaa validaattorin tarkan ja täydellisen tuloksen ja säilyttää paluukoodin 26.
