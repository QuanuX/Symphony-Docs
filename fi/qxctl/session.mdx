`qxctl knowledge session ...` -kielioppi avaa ei-kanonisia todennettuja istuntoja yhden tarkan, sidotun koordinaattorin ja yhden TOPS-rajatun SSIAG-päätepisteen kautta. Erillinen `session features ...` -kielioppi ohjaa pysyvää SSFV-ylläpitovirtaa.

## Perusistunnon kielioppi

```bash Session lifecycle
qxctl knowledge session begin
qxctl knowledge session status
qxctl knowledge session checkpoint
qxctl knowledge session close
qxctl knowledge session recover
```

Jokainen kutsu pyytää tuoreen tarkan myönnön ja validoi:

- Subjektin ja kohteen identiteetin
- Käytännön ja konfiguraation tilan
- Voimassaolon päättymisen
- Kutsujaluokkaneutraaliuden
- Siirtokelvottomuuden
- Kanonisen soveltamisen estämisen
- Kyvykkyyssidonnan

Istuntotodisteet valtuuttavat vain nimetyn suojatun ei-kanonisen operaation. Pidä istunto- ja täsmäytyslokit erillään; käytä kontekstiviittauksia ainoastaan niiden yhdistämiseen.

## SSFV-ylläpitovirta

```bash Features stream
qxctl knowledge session features begin
qxctl knowledge session features status
qxctl knowledge session features checkpoint
qxctl knowledge session features close
qxctl knowledge session features recover
```

Features-virta on erillinen pysyvä SSFV-ylläpitokonteksti. Muutokset edellyttävät:

- Avointa todennettua perusistuntoa
- Tarkkoja koordinaattori- ja SSFV-sidontoja
- Vakaita operaatiotunnisteita
- Tarkkaa compare-and-swap-operaatiota
- Tuoreita SSIAG-todisteita

<Note>
  Säilytä perustason tilannevedos ja sen alkuperäinen moottori-identiteetti yhteensopivien päivitysten ja palautusten yli. Valinnaisten Maestro-todisteiden on oltava täydellinen todennettu inventaario; kun Maestro tarkoituksella puuttuu, kirjaa eksplisiittinen ei-määritetty-syy. `review_required` on todiste kutsujan tarkastettavaksi, ei ratifiointi.
</Note>
