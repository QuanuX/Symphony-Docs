Šajā publiskajā krātuvē ir iepriekšējs kvantitatīvās QuanuX lietotnes momentuzņēmums ar pirmsizlaides mērķi v0.0.1-pre. Tā README apraksta Python serveri, Node/pnpm klienta rīkus un darbvirsmas izstrādes ceļu ar Tauri.

## Nošķiriet laidienus {#keep-the-releases-distinct}

Iepriekšējā quanux Conda pakotne un lietotnes iestatīšanas instrukcijas attiecas uz šo momentuzņēmumu. Tās nav Symphony Public Beta 0.2.0-beta.1 instalēšanas veids.

Pašreizējam natīvajam Symphony laidienam izmantojiet [Symphony lejupielādes un precīzos Anaconda profilus](https://quanux.org/downloads) un [beta testēšanas ceļvedi](https://quanux.org/beta).

## Izpētiet momentuzņēmumu {#explore-the-snapshot}

Pētot arhitektūru vai atveidojot vēsturisko darbību, izmantojiet šīs krātuves README, licenci, atkarību manifestus un reģistrēto pirmkoda revīziju. Tās eksperimentālās API un lietotnes modeli nedrīkst klusībā pārnest uz pašreizējo Symphony arhitektūru vai gatavības apgalvojumiem.
