Šajā krātuvē ir Gemini CLI paplašinājums iepriekšējai QuanuX lietotnei. Tā README apraksta GEMINI.md konteksta ielādi, Python stratēģiju pakotņu ģenerēšanu mapē server/strategies un izpildlaika dzinēja statusa pārbaudi.

## Pirmkoda izvērtēšana {#source-evaluation}

Krātuvē aprakstītas Python atkarības un paplašinājuma sasaiste ar Gemini CLI. Izlasiet tās pašreizējo README un atkarību failus, pārskatiet paplašinājumu un testējiet to ar atbilstošo lietotnes momentuzņēmumu izolētā darbvietā.

## Saistība ar Symphony {#relationship-to-symphony}

Šis projekts atšķiras no Symphony natīvā beta klienta un nenodrošina saderību ar parakstīto 0.2.0-beta.1 pakotņu kopu. Pašreizējam kvalificētajam Symphony klientam izmantojiet [beta lejupielādes un klienta iestatīšanu](https://quanux.org/downloads). Uzskatiet mantotās lietotnes ceļus un komandu piemērus par šīs krātuves daļu, nevis par universāliem Symphony līgumiem.
