Symphony ir atvērtā pirmkoda quantOS, kas izstrādāta, izmantojot Vector-Graph Application Architecture. Natīvie dzinēji un SDK veic jomas darbu; qxctl nodrošina aģentiem un cilvēkiem kopīgu vadības virsmu. Lietotāji paši izvēlas savus dzinējus, stratēģijas, pakalpojumu sniedzējus un topoloģiju.

## Publiskā beta versija {#public-beta}

Publicētais laidiens ir **0.2.0-beta.1**, kas palaists 2026. gada 16. novembrī. Tas nodrošina 59 noklusējuma pakotnes katram precīzajam profilam, natīvu Codex klientu, SDK eksportus un neobligātu atbilstošo pirmkodu.

| Mērķis | Arhitektūra |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

Sāciet ar [lejupielādēm un Anaconda instrukcijām](https://quanux.org/downloads), pēc tam izmantojiet [beta versijas iespēju un testēšanas ceļvedi](https://quanux.org/beta).

## Iespējas, ko izpētīt {#capabilities-to-explore}

- qxctl manifesti, versijas, instalēto īpašnieku pārbaude un skaidri noteikta administrēšana.
- SQV tveršana, metadati, plūsma, pārvēršana veselos skaitļos, lokālās krātuves, atkārtota atskaņošana un kontrolpunkti.
- SBV ierobežota backtest izpēte, cenzs, natīva novērtēšana, saglabātie rezultāti, atcelšana un atkopšana.
- SHV avotos balstīti aparatūras katalogi, prasības, grafi un publikāciju priekšskatījumi.
- SCV pakalpojumu sniedzēju zināšanas un SNV Node identitāte, resursi, klasteru attiecības un nosaukšana.
- SSIAG autorizācija, STAV audita pierādījumi, kompozīcija un zināšanu pārvaldība.

## Kvalifikācijas robežas {#qualification-boundaries}

Laidiena ieraksts identificē precīzos kvalificētos baitus. Fiziskam DGX Spark, GPU darbībai un reāllaika izvietošanai pie pakalpojumu sniedzējiem nepieciešami atsevišķi pierādījumi. Vispārējā akreditācijas datu piegādē un natīvajos pakalpojumu sniedzēju tiltos ir skaidri norādītas implementācijas nepilnības; adaptera instalēšana nekvalificē reāllaika savienojumu. Labojumi pirmkoda galvenajā zarā neaizstāj parakstītos beta artefaktus.

Pirms katra izvēlētā moduļa izmantošanas izlasiet [pašreizējo pirmkoda README un uzturēšanas piezīmes](https://github.com/QuanuX/Symphony#readme) un tā specifikāciju.
