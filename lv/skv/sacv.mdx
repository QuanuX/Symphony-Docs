Symphony API Contract Vector (SACV) pārvalda versiju API līgumus visā platformā. Tā dzinējs ir neatkarīgi instalējams C++ process, kas veic ierobežotu OpenAPI 3.2.0 JSON validāciju, deterministiskus saderības salīdzinājumus un vienreizējus inventārus. Galapunktu semantika paliek domēnam piederošajam vektoram vai modulim; SACV pārvalda līguma formu un saderību.

## Operācijas

- **Inspect un check**: validē, vai OpenAPI 3.2.0 JSON dokuments atbilst ierobežotajam profilam.
- **Diff**: aprēķina deterministiskus saderības salīdzinājumus starp līgumu versijām.
- **Propose**: pieņem izsaucēja deklarētus reģistra priekšlikumus jauniem vai mainītiem līgumiem.
- **Project**: izvada vienreizējus inventārus pārskatītājiem un lejupējiem rīkiem.

## Ko pārvalda SACV

SACV ierobežo:

- Līguma formu (OpenAPI 3.2.0 ar SACV profilu)
- Saderības klasifikāciju starp versijām
- Reģistra dalību pieņemtajiem līgumiem

Tas nedara šo:

- Tam nepieder galapunktu semantika (to patur katrs vektors vai modulis)
- Neģenerē SDK, nepublicē artefaktus un neizsniedz žetonus
- Nenozīmē, ka pastāv aktīva tīkla virsma (nākotnes privāta API pieminēšana to neizveido)

<Note>
  SACV tikai lasa, vaicā, validē un ierosina. Programmatiska kanoniskā piemērošana ir atspējota visiem SKV dzinējiem.
</Note>
