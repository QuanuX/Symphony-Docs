Gramatika `qxctl validate ...` administrē Symphony Validator aizsargāto brīdinājumu politiku, bāzlīniju un attēlošanas gramatiku. Neatkarīgi instalētais C++ validators rada nemainīgus neapstrādātus pierādījumus; qxctl administrē no izsaucēja neatkarīgu aizsargātu attēlošanu, nemainot noteikšanu.

## Ko aptver qxctl validate

- Deviņas aizsargātas brīdinājumu dzīves cikla lapas
- Precīzais ar kvīti nodrošinātais saknes kopsavilkuma maršruts
- Bāzlīnijas pārvaldība un izmaiņu atskaites
- Attēlošanas gramatika rindu izvadei un strukturētam JSON

Katra lapa pirms aizsargātās brīdinājumu politikas piemērošanas validē validatora precīzo kvīti un strukturētās jaucējvērtības.

## Robeža

<Warning>
  qxctl validate nevar labot failus, neko publicēt vai ignorēt neapstrādātus detektora pierādījumus. Brīdinājuma statuss ietekmē attēlošanu, nevis noteikšanu.
</Warning>

- Nekāda brīdinājumu apslāpēšana ārpus aizsargātās politikas
- Nekāda validatora izvades modificēšana
- Nekāds izdomāts pārklājums nepieejamam maršrutam

## Biežākie lietojumi

- Izveidot vai atiestatīt brīdinājumu bāzlīniju
- Apstiprināt vai atkārtoti atvērt pārvaldītu vēsturisku brīdinājumu
- Izvadīt ar kvīti nodrošināto saknes kopsavilkumu, kas parādās repozitorija README

Validators, uz kura balstās šī gramatika, pārbauda līgumu formu, pašreizējā pirmkoda noslēgtību, invariantu īpašumtiesības, funkciju administrēšanu, laidienus un mašīnai piederošo saknes kopsavilkumu.
