Questo repository contiene un'estensione di Gemini CLI per la precedente applicazione QuanuX. Il suo README descrive il caricamento del contesto GEMINI.md, la generazione di pacchetti di strategie Python in server/strategies e il controllo dello stato del motore di runtime.

## Valutazione del codice sorgente {#source-evaluation}

Il repository descrive le dipendenze Python e il collegamento dell'estensione con Gemini CLI. Leggi il README e i file delle dipendenze attuali, rivedi l'estensione e testala con lo snapshot dell'applicazione corrispondente in uno spazio di lavoro isolato.

## Relazione con Symphony {#relationship-to-symphony}

Questo progetto è distinto dal client beta nativo di Symphony e non stabilisce la compatibilità con l'insieme di pacchetti firmato 0.2.0-beta.1. Per l'attuale client Symphony qualificato, usa [i download della beta e la configurazione del client](https://quanux.org/downloads). Considera i percorsi dell'applicazione legacy e gli esempi di comandi come propri di questo repository, non come contratti universali di Symphony.
