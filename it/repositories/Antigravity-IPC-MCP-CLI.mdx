Questo progetto fornisce superfici native di IPC locale e MCP per Antigravity e altri flussi di lavoro di client di agenti, con supporto per la CLI e una configurazione di connessione esplicita.

## Cosa valutare {#what-to-evaluate}

- Esamina i requisiti di build C++26 dichiarati e il contratto del protocollo.
- Ispeziona le scelte di trasporto stdio e IPC locale e i relativi limiti di autorità.
- Genera e rivedi una configurazione client per l'host previsto.
- Esegui i test del repository prima di valutare una sessione reale di un client di agenti.

Le integrazioni di Antigravity, agy, Gemini, Codex e Claude mantengono requisiti di configurazione e qualificazione specifici per ciascun client. Questo repository autonomo è distinto dal client Codex incluso nella distribuzione firmata di Symphony. Non dedurre l'inclusione nella beta binaria né l'approvazione in directory di terze parti dalla disponibilità del codice sorgente.
