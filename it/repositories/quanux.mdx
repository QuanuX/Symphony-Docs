Questo repository pubblico contiene uno snapshot precedente dell'applicazione quantitativa QuanuX, con un obiettivo di pre-release v0.0.1-pre. Il suo README descrive un server Python, strumenti client Node/pnpm e un percorso di sviluppo desktop con Tauri.

## Mantieni distinte le release {#keep-the-releases-distinct}

Il precedente pacchetto Conda quanux e le istruzioni di configurazione dell'applicazione appartengono a questo snapshot. Non sono il percorso di installazione di Symphony Public Beta 0.2.0-beta.1.

Per l'attuale release nativa di Symphony, usa [i download di Symphony e i profili Anaconda esatti](https://quanux.org/downloads) e [la guida ai test della beta](https://quanux.org/beta).

## Esplora lo snapshot {#explore-the-snapshot}

Usa il README, la licenza, i manifest delle dipendenze e la revisione del codice sorgente registrata di questo repository quando ne studi l'architettura o riproduci il comportamento storico. Le sue API sperimentali e il suo modello applicativo non devono essere promossi silenziosamente nell'architettura attuale di Symphony né in affermazioni di prontezza.
