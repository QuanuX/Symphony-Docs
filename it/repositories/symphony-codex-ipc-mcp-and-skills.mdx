Questo progetto fornisce un bridge MCP nativo in C++, cataloghi di strumenti, generatori di configurazione client e skill per le operazioni locali di Symphony tramite qxctl. Preserva l'instradamento esatto verso i proprietari e l'autorità esplicita.

## Inizia con il client beta {#start-with-the-beta-client}

Per il percorso binario qualificato, usa il client fornito con [Symphony 0.2.0-beta.1](https://quanux.org/downloads). Segui la [guida alla conservazione e alla configurazione del client](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md). Codex è il client qualificato principale; gli adattatori di configurazione esistenti per Claude, Antigravity e generici mantengono i propri limiti.

## Esplora {#explore}

- Scopri strumenti strutturati e instrada le operazioni verso i proprietari qxctl installati.
- Genera un profilo di connessione isolato e un frammento di configurazione client.
- Inizia con operazioni di lettura; abilita l'autorità di scrittura solo tramite flussi del proprietario documentati.
- Ispeziona le skill del progetto e le istruzioni di build e test a livello di codice sorgente.

Il contratto del protocollo è fissato in questo repository. Usa la versione dichiarata e i prerequisiti di build invece di sostituirli silenziosamente con una revisione MCP più recente. Un repository pubblico o una configurazione client locale non costituisce un'affermazione di approvazione in una directory di plugin di terze parti.
