This project supplies native local IPC and MCP surfaces for Antigravity and other agent-client workflows, with CLI support and explicit connection configuration.

## What to evaluate

- Review the declared C++26 build requirements and protocol contract.
- Inspect stdio and local IPC transport choices and their authority boundaries.
- Generate and review a client configuration for the intended host.
- Run the repository's tests before evaluating an actual agent-client session.

Antigravity, agy, Gemini, Codex and Claude integrations retain client-specific configuration and qualification requirements. This standalone repository is distinct from the Codex client bundled in the signed Symphony distribution. Do not infer binary-beta inclusion or third-party directory approval from source availability.
