This repository is the source for the Mintlify site at [docs.quanux.org/symphony](https://docs.quanux.org/symphony). It contains platform doctrine, architecture, vector and owner references, qxctl documentation, translations and changelog material.

## Public beta documentation

Start with [the beta capability guide](https://quanux.org/beta), [downloads and Anaconda installation](https://quanux.org/downloads), then the documentation for the module you select.

Each public repository has a dedicated page under Public repositories. Short addresses such as docs.quanux.org/NemoSymphTron resolve to that repository's documentation.

## Source and publication discipline

Current repository implementation and exact published release artifacts determine readiness. Historical documentation and source-main updates are different evidence. Retain version provenance, distinguish optional companions from binary-release contents, and preserve existing translations and source links when updating pages.

Automated repository refreshes are scheduled in 30-minute start slots on November 17 and 18, 2026, beginning at 00:01 America/New_York. Pages will evolve as new evidence and releases become available.
