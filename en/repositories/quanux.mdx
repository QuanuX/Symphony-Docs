This public repository contains an earlier QuanuX quantitative application snapshot, with a pre-release target of v0.0.1-pre. Its README describes a Python server, Node/pnpm client tooling and a Tauri desktop development path.

## Keep the releases distinct

The earlier quanux Conda package and application setup instructions belong to this snapshot. They are not the installation route for Symphony Public Beta 0.2.0-beta.1.

For the current native Symphony release, use [Symphony downloads and exact Anaconda profiles](https://quanux.org/downloads) and [the beta test guide](https://quanux.org/beta).

## Explore the snapshot

Use this repository's README, license, dependency manifests and recorded source revision when investigating its architecture or reproducing historical behavior. Its experimental APIs and application model must not be silently promoted into current Symphony architecture or readiness claims.
