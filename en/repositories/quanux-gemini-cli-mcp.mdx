This repository contains a Gemini CLI extension for the earlier QuanuX application. Its README describes loading GEMINI.md context, generating Python strategy packages into server/strategies, and checking runtime-engine status.

## Source evaluation

The repository describes Python dependencies and linking the extension with Gemini CLI. Read its current README and dependency files, review the extension, and test it against the matching application snapshot in an isolated workspace.

## Relationship to Symphony

This project is distinct from Symphony's native beta client and does not establish compatibility with the signed 0.2.0-beta.1 package set. For the current qualified Symphony client, use [the beta downloads and client setup](https://quanux.org/downloads). Treat legacy application paths and command examples as belonging to this repository, not as universal Symphony contracts.
