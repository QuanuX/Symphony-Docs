Symphony is the open-source quantOS developed through Vector-Graph Application Architecture. Native engines and SDKs perform the domain work; qxctl gives agents and people a common control surface. Users choose their own engines, strategies, providers and topology.

## Public beta

The published release is **0.2.0-beta.1**, launched November 16, 2026. It supplies 59 default packages per exact profile, a native Codex client, SDK exports and optional corresponding source.

| Target | Architecture |

Start at [downloads and Anaconda instructions](https://quanux.org/downloads), then use the [beta capability and testing guide](https://quanux.org/beta).

## Capabilities to explore

- qxctl manifests, versions, installed-owner inspection and explicit administration.
- SQV capture, metadata, flow, integer conversion, local stores, replay and checkpoints.
- SBV bounded backtest research, census, native evaluation, retained results, cancellation and recovery.
- SHV source-backed hardware catalogues, requirements, graphs and publication previews.
- SCV provider knowledge and SNV Node identity, resources, cluster relationships and naming.
- SSIAG authorization, STAV audit evidence, composition and knowledge governance.

## Qualification boundaries

The release record identifies exact qualified bytes. Physical DGX Spark, GPU behavior and live-provider deployments require separate evidence. General credential delivery and native provider bridges have explicit implementation gaps; installing an adapter does not qualify a live connection. Source-main repairs do not replace signed beta artifacts.

Read the [current source README and maintenance notes](https://github.com/QuanuX/Symphony#readme) and each selected module's specification before operating it.
