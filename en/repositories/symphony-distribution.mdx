This repository owns the distribution and release evidence for Symphony. The public beta **0.2.0-beta.1** was published November 16, 2026.

## Download and install

Use [quanux.org/downloads](https://quanux.org/downloads) for platform installers, Anaconda instructions and descriptions of every package. The [release page](https://github.com/QuanuX/symphony-distribution/releases/tag/v0.2.0-beta.1) identifies the exact artifacts.

The profiles are macOS 15 ARM64, Ubuntu 24.04 AMD64, Ubuntu 24.04 ARM64 and Ubuntu 26.04 AMD64. Each includes 59 independently maintainable default packages plus optional corresponding source. Linux AMD64 cohorts share a Conda subdirectory but are distinct qualified builds: use the exact profile's explicit list.

## Verification and first use

1. Read the [installation guide](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md).
2. Verify the signed manifest, release index and selected files with the pinned verifier.
3. Install into a new private prefix as your normal user.
4. Retain verified binaries into a separate private custody directory.
5. Review the generated client configuration and explicitly select native owners and authority.

Conda 26.10.0 was qualified. Python 3.11+ and OpenSSL are needed for verification and setup; a compiler is not required to run the supplied binaries. The Mac PKG is not Apple Developer ID signed or notarized. Detached verification does not alter system trust.

## Lifecycle evidence

The release qualifies installer/first-use paths, 22 Codex cases and 182 package-maintenance transactions per profile. Revision 0 → 1 → 0 uses identical native bytes. Distinct native-version upgrades, retained copies and running owner lifecycles remain separate. See the [retention guide](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/RETENTION.md).
