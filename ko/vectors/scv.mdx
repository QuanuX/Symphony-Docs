Symphony Cloud Vector(SCV)는 외부 하드웨어 리소스와, 클러스터·학습·연구·데이터 작업을 좌우하는 제공자 현실에 대한 비공개 의미 지식을 소유합니다. 제공자의 순위를 매기거나 시도할 수 있는 작업에 경계를 두지 않고 제공자 상품, 리전, 인프라 도메인, 제약 조건, 관찰된 가용성을 매핑합니다.

## 제공자 커버리지

SCV는 다음 제공자와 리소스 유형을 다룹니다.

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- 사용자 소유 하드웨어(외부 리소스와의 비교가 필요한 경우)

## 이식 가능한 제공자 패키지와 구성

SCV는 qxctl을 통해 이식 가능한 제공자 패키지를 제공합니다. 요구 사항, 제공자 권한, 레시피 대안, 실행 결정에 대한 통제권은 사용자에게 있습니다. qxctl은 보존된 워크플로와 보호된 그래프 선택을 지원하므로 제공자에 다시 쿼리하지 않고도 정확한 증거를 재생할 수 있습니다.

## 선택적 DuckDB 커넥터

`scv-graph-duckdb-connector`는 변경 불가능한 네이티브 그래프의 범위가 제한된 관계형 프로젝션을 추가합니다. DuckDB는 사용자가 선택한 기본 SQL 데이터베이스입니다. 향후에는 추가 어댑터를 통해 전용 그래프 엔진을 선택할 수도 있습니다.

## 개인정보 보호와 주권

설치된 SCV 지식 그래프는 사용자의 비공개 설치본에 속합니다. 사용자가 제공한 계정, 잔액, 권한, 계약상 제약은 명시적으로 활성화된 관찰 인터페이스를 통해서만 사용됩니다. 비공개 사실은 공식 Symphony 소스 진실에 포함되지 않습니다.

## 버전이 지정된 인터페이스 증분

SCV 릴리스는 추가 방식이며 정확한 버전으로 지정됩니다. 이전 설치본은 정확한 범위에서 계속 호출할 수 있습니다. 현재 증분에는 네이티브 작업, 코퍼스 스냅샷, 해석 프로필, 이식 가능한 제공자 팩, 구성 워크플로, 의무 추적, 증거 번들이 포함됩니다. 각 증분은 이전의 경로, 기본값, 기록을 보존합니다.
