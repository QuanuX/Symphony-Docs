Symphony Quantitative Vector(SQV)는 정량 연구, 트레이딩 시스템 구축, 실행 지원, 이후의 정량 엔진을 위한 재사용 가능한 프레임워크 계약을 소유합니다. 전략 로직은 항상 사용자에게 속합니다. SQV는 프레임워크 인터페이스와 정확한 호환성 증거를 제공하지만, 사용자의 상품, 피드, 구독, 주문 로직, 실행 모델을 결정하지 않습니다.

## 사용자 전략 경계

전략 로직의 소유권은 전적으로 사용자에게 있습니다. SQV는 다음을 하지 않습니다.

- 상품이나 데이터 피드 선택
- 구독 필드나 시장 심도 정의
- 실패 동작이나 정규화 규칙 결정
- 주문 로직이나 실행 모델 작성
- 내부 모듈 구조 설계

Symphony는 호환성 증거와 지원되는 작업을 제공합니다. 전략의 순위를 매기거나 트레이딩 결정에 플랫폼 규칙을 강요하지 않습니다.

## SOOV: Symphony Orchestra Omega Vector

SOOV는 SQV 아래의 첫 번째 명명된 하위 벡터입니다. 과거 QuanuX 작업을 바탕으로 한 향후의 고성능 C++ 전용 FIX 아키텍처를 나타냅니다. SOOV는 트레이딩 통신을 위한 범위가 제한된 결정적 메시징 계층으로 계획되어 있습니다. 상세한 FIX 동작은 아직 정규화되지 않았으며, 현재 FIX 세션, 피드 어댑터, 브로커 통합은 구현되어 있지 않습니다.

## 향후 범위

SQV는 이후 제공 단계 전반에서 승인된 정량 프레임워크 구성 요소가 자리할 곳으로 계획되어 있습니다. 예상 영역은 다음과 같습니다.

- 백테스팅 엔진
- 브로커 C++ API
- 지표 라이브러리
- 정량 수학
- 데이터 스트림 아키텍처

이들 중 어느 것도 각 계약이 승인되기 전까지는 구현되지 않습니다.

## 현재 상태

SQV는 정규 아키텍처 계약일 뿐입니다. 현재 SQV 또는 SOOV 엔진, FIX 세션, 피드 어댑터, 전략 런타임, 브로커 통합, 백테스터, 지표 라이브러리, 데이터 스트림 구성 요소는 구현되어 있지 않습니다.
