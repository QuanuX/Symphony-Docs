Symphony는 Vector-Graph Application Architecture를 통해 개발된 오픈 소스 quantOS입니다. 네이티브 엔진과 SDK가 도메인 작업을 수행하고, qxctl은 에이전트와 사람에게 공통 제어 표면을 제공합니다. 엔진, 전략, 제공자, 토폴로지는 사용자가 직접 선택합니다.

## 공개 베타 {#public-beta}

게시된 릴리스는 2026년 11월 16일에 출시된 **0.2.0-beta.1**입니다. 정확한 프로필마다 59개의 기본 패키지, 네이티브 Codex 클라이언트, SDK 내보내기, 선택형 대응 소스를 제공합니다.

| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |

[다운로드 및 Anaconda 지침](https://quanux.org/downloads)에서 시작한 다음 [베타 기능 및 테스트 가이드](https://quanux.org/beta)를 활용하세요.

## 살펴볼 기능 {#capabilities-to-explore}

- qxctl 매니페스트, 버전, 설치된 오너 검사, 명시적 관리.
- SQV 캡처, 메타데이터, 플로, 정수 변환, 로컬 저장소, 재생, 체크포인트.
- SBV의 범위 제한 백테스트 리서치, 센서스, 네이티브 평가, 보존된 결과, 취소 및 복구.
- SHV의 소스 기반 하드웨어 카탈로그, 요구 사항, 그래프, 게시 미리 보기.
- SCV 제공자 지식과 SNV Node ID, 리소스, 클러스터 관계, 명명.
- SSIAG 권한 부여, STAV 감사 근거, 구성, 지식 거버넌스.

## 인증 경계 {#qualification-boundaries}

릴리스 기록은 인증된 정확한 바이트를 식별합니다. 물리적 DGX Spark, GPU 동작, 라이브 제공자 배포에는 별도의 근거가 필요합니다. 일반적인 자격 증명 전달과 네이티브 제공자 브리지에는 명시적인 구현 공백이 있으며, 어댑터를 설치한다고 해서 라이브 연결이 인증되지는 않습니다. 소스 메인 브랜치의 수정 사항이 서명된 베타 아티팩트를 대체하지는 않습니다.
