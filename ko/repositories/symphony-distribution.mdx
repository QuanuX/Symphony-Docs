이 저장소는 Symphony의 배포와 릴리스 근거를 담당합니다. 공개 베타 **0.2.0-beta.1**은 2026년 11월 16일에 게시되었습니다.

## 다운로드 및 설치 {#download-and-install}

플랫폼별 설치 프로그램, Anaconda 지침, 모든 패키지 설명은 [quanux.org/downloads](https://quanux.org/downloads)를 이용하세요. [릴리스 페이지](https://github.com/QuanuX/symphony-distribution/releases/tag/v0.2.0-beta.1)에서 정확한 아티팩트를 확인할 수 있습니다.

프로필은 macOS 15 ARM64, Ubuntu 24.04 AMD64, Ubuntu 24.04 ARM64, Ubuntu 26.04 AMD64입니다. 각 프로필에는 독립적으로 유지 관리할 수 있는 59개의 기본 패키지와 선택형 대응 소스가 포함됩니다. Linux AMD64 코호트는 Conda 하위 디렉터리를 공유하지만 서로 다른 인증 빌드이므로, 정확한 프로필의 명시적 목록을 사용하세요.

## 검증 및 첫 사용 {#verification-and-first-use}

1. [설치 가이드](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md)를 읽으세요.
2. 고정된 검증 도구로 서명된 매니페스트, 릴리스 인덱스, 선택한 파일을 검증하세요.
3. 일반 사용자로 새 비공개 프리픽스에 설치하세요.
4. 검증된 바이너리를 별도의 비공개 보관 디렉터리에 보존하세요.
5. 생성된 클라이언트 구성을 검토하고 네이티브 오너와 권한을 명시적으로 선택하세요.

Conda 26.10.0이 인증되었습니다. 검증과 설정에는 Python 3.11 이상과 OpenSSL이 필요하며, 제공된 바이너리를 실행하는 데 컴파일러는 필요하지 않습니다. Mac PKG는 Apple Developer ID로 서명되거나 공증되지 않았습니다. 분리된 검증은 시스템 신뢰 설정을 변경하지 않습니다.

## 수명 주기 근거 {#lifecycle-evidence}

이 릴리스는 프로필별로 설치 프로그램 및 첫 사용 경로, 22개의 Codex 사례, 182개의 패키지 유지 관리 트랜잭션을 인증합니다. 리비전 0 → 1 → 0은 동일한 네이티브 바이트를 사용합니다. 다른 네이티브 버전으로의 업그레이드, 보존된 사본, 실행 중인 오너의 수명 주기는 별도로 유지됩니다. [보존 가이드](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/RETENTION.md)를 참고하세요.
