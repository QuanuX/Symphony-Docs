이 저장소에는 이전 QuanuX 애플리케이션을 위한 Gemini CLI 확장이 포함되어 있습니다. README에서는 GEMINI.md 컨텍스트 로드, server/strategies에 Python 전략 패키지 생성, 런타임 엔진 상태 확인 방법을 설명합니다.

## 소스 평가 {#source-evaluation}

저장소에서는 Python 종속성과 확장을 Gemini CLI에 연결하는 방법을 설명합니다. 최신 README와 종속성 파일을 읽고, 확장을 검토한 다음, 격리된 작업 공간에서 일치하는 애플리케이션 스냅샷으로 테스트하세요.

## Symphony와의 관계 {#relationship-to-symphony}

이 프로젝트는 Symphony의 네이티브 베타 클라이언트와 별개이며, 서명된 0.2.0-beta.1 패키지 세트와의 호환성을 보장하지 않습니다. 현재 인증된 Symphony 클라이언트는 [베타 다운로드 및 클라이언트 설정](https://quanux.org/downloads)을 사용하세요. 레거시 애플리케이션 경로와 명령 예제는 Symphony의 보편적인 계약이 아니라 이 저장소에 속한 것으로 취급하세요.
