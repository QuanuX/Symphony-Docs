Symphony Cloud Vector (SCV) eier privat semantisk kunnskap om eksterne maskinvareressurser og de leverandørrealitetene som former klyngene, treningen, forskningen og dataarbeidet ditt. Den kartlegger leverandørtilbud, regioner, infrastrukturdomener, begrensninger og observert tilgjengelighet uten å rangere leverandører eller legge begrensninger på hva du kan forsøke.

## Leverandørdekning

SCV dekker følgende leverandører og ressurstyper:

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- Brukereid maskinvare (der det kreves sammenligning med eksterne ressurser)

## Portable leverandørpakker og komposisjon

SCV eksponerer portable leverandørpakker via qxctl. Du beholder kontrollen over krav, leverandørtillatelser, oppskriftsalternativer og kjøringsbeslutninger. qxctl støtter bevarte arbeidsflyter og beskyttet grafvalg, slik at du kan spille av eksakt bevis på nytt uten å spørre leverandørene på nytt.

## Valgfri DuckDB-konnektor

`scv-graph-duckdb-connector` legger til en avgrenset relasjonell projeksjon av uforanderlige native grafer. DuckDB er den brukervalgte standard SQL-databasen. Du kan i fremtiden velge dedikerte grafmotorer gjennom ytterligere adaptere.

## Personvern og suverenitet

En installert SCV-kunnskapsgraf tilhører din private installasjon. Brukeroppgitte kontoer, saldoer, tillatelser og kontraktsmessige begrensninger brukes bare gjennom eksplisitt aktiverte observasjonsflater. Private fakta havner ikke i Symphonys offisielle kildesannhet.

## Versjonerte grensesnittinkrementer

SCV-utgivelser er additive og har eksakte versjoner. Tidligere installasjoner kan fortsatt kalles innenfor sine eksakte omfang. Nåværende inkrementer omfatter native operasjoner, korpusøyeblikksbilder, tolkningsprofiler, portable leverandørpakker, komposisjonsarbeidsflyter, sporing av forpliktelser og bevispakker. Hvert inkrement bevarer tidligere ruter, standardverdier og poster.
