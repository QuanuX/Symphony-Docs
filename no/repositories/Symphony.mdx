Symphony er det åpne quantOS-et som er utviklet etter Vector-Graph Application Architecture. Native motorer og SDK-er utfører domenearbeidet; qxctl gir agenter og mennesker en felles kontrollflate. Brukerne velger sine egne motorer, strategier, leverandører og topologi.

## Offentlig beta {#public-beta}

Den publiserte versjonen er **0.2.0-beta.1**, lansert 16. november 2026. Den leverer 59 standardpakker per nøyaktig profil, en native Codex-klient, SDK-eksporter og valgfri tilhørende kildekode.

| Mål | Arkitektur |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

Start med [nedlastinger og Anaconda-instruksjoner](https://quanux.org/downloads), og bruk deretter [veiledningen til betaens funksjoner og testing](https://quanux.org/beta).

## Funksjoner å utforske {#capabilities-to-explore}

- qxctl-manifester, versjoner, inspeksjon av installerte eiere og eksplisitt administrasjon.
- SQV-innsamling, metadata, flyt, heltallskonvertering, lokale lagre, avspilling og kontrollpunkter.
- SBV-forskning med avgrensede backtester, census, native evaluering, bevarte resultater, avbrytelse og gjenoppretting.
- SHV-maskinvarekataloger med kildegrunnlag, krav, grafer og forhåndsvisninger av publisering.
- SCV-leverandørkunnskap og SNV-identitet for Nodes, ressurser, klyngerelasjoner og navngiving.
- SSIAG-autorisasjon, STAV-revisjonsbevis, komposisjon og kunnskapsstyring.

## Kvalifiseringsgrenser {#qualification-boundaries}

Versjonsdokumentasjonen identifiserer de nøyaktige kvalifiserte bytene. En fysisk DGX Spark, GPU-oppførsel og live-utrullinger hos leverandører krever separate bevis. Generell levering av påloggingsinformasjon og native leverandørbroer har eksplisitte implementeringshull; å installere en adapter kvalifiserer ikke en live-tilkobling. Rettelser på hovedgrenen til kildekoden erstatter ikke signerte betaartefakter.

Les den [gjeldende README-en og vedlikeholdsnotatene for kildekoden](https://github.com/QuanuX/Symphony#readme) og spesifikasjonen for hver valgte modul før du bruker den.
