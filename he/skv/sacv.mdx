Symphony API Contract Vector (SACV) מנהל חוזי API עם גרסאות לרוחב הפלטפורמה. המנוע שלו הוא תהליך C++ הניתן להתקנה באופן עצמאי, המבצע אימות JSON מוגבל של OpenAPI 3.2.0, הפרשי תאימות דטרמיניסטיים ומלאים חד-פעמיים. הסמנטיקה של נקודות הקצה נשארת בידי הווקטור או המודול שבבעלותם התחום; SACV מנהל את צורת החוזה ואת התאימות.

## פעולות

- **Inspect ו-check**: אימות שמסמך JSON של OpenAPI 3.2.0 תואם לפרופיל המוגבל.
- **Diff**: חישוב הפרשי תאימות דטרמיניסטיים בין גרסאות חוזה.
- **Propose**: קבלת הצעות רישום המוצהרות על ידי הקורא עבור חוזים חדשים או משתנים.
- **Project**: פליטת מלאים חד-פעמיים לסוקרים ולכלים במורד הזרם.

## מה SACV מנהל

SACV תוחם:

- את צורת החוזה (OpenAPI 3.2.0 עם פרופיל SACV)
- את סיווג התאימות בין גרסאות
- את החברות ברישום עבור חוזים שהתקבלו

הוא אינו:

- הבעלים של הסמנטיקה של נקודות הקצה (כל וקטור או מודול שומר עליה)
- מייצר SDK-ים, מפרסם ממצאים או מנפיק אסימונים
- מרמז על קיומו של משטח רשת חי (אזכור של API פרטי עתידי אינו יוצר אותו)

<Note>
  SACV מוגבל לקריאה, שאילתה, אימות והצעה בלבד. apply קנוני פרוגרמטי מושבת בכל מנועי SKV.
</Note>
