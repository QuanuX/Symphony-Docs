Symphony הוא quantOS בקוד פתוח שפותח לפי Vector-Graph Application Architecture. מנועים ו-SDK נייטיביים מבצעים את עבודת התחום; qxctl מעניק לסוכנים ולאנשים משטח בקרה משותף. המשתמשים בוחרים בעצמם את המנועים, האסטרטגיות, הספקים והטופולוגיה.

## גרסת בטא ציבורית {#public-beta}

הגרסה שפורסמה היא **0.2.0-beta.1**, שהושקה ב-16 בנובמבר 2026. היא מספקת 59 חבילות ברירת מחדל לכל פרופיל מדויק, לקוח Codex נייטיבי, ייצואי SDK וקוד מקור תואם אופציונלי.

| יעד | ארכיטקטורה |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

התחילו ב[הורדות ובהוראות Anaconda](https://quanux.org/downloads), ולאחר מכן השתמשו ב[מדריך היכולות והבדיקות של גרסת הבטא](https://quanux.org/beta).

## יכולות לחקור {#capabilities-to-explore}

- מניפסטים של qxctl, גרסאות, בדיקת בעלים מותקנים וניהול מפורש.
- לכידה, מטא-נתונים, זרימה, המרה למספרים שלמים, מאגרים מקומיים, הפעלה חוזרת ונקודות ביקורת ב-SQV.
- מחקר backtest תחום, מפקד, הערכה נייטיבית, תוצאות שנשמרו, ביטול ושחזור ב-SBV.
- קטלוגי חומרה מבוססי מקורות, דרישות, גרפים ותצוגות מקדימות של פרסום ב-SHV.
- ידע על ספקים ב-SCV, וזהות Node, משאבים, קשרי אשכול ומתן שמות ב-SNV.
- הרשאות SSIAG, ראיות ביקורת STAV, הרכבה וממשל ידע.

## גבולות ההסמכה {#qualification-boundaries}

רשומת הגרסה מזהה את הבתים המוסמכים המדויקים. DGX Spark פיזי, התנהגות GPU ופריסות חיות מול ספקים דורשים ראיות נפרדות. במסירה הכללית של אישורי גישה ובגשרים הנייטיביים לספקים יש פערי מימוש מפורשים; התקנת מתאם אינה מסמיכה חיבור חי. תיקונים בענף הראשי של קוד המקור אינם מחליפים את תוצרי הבטא החתומים.

קראו את [ה-README העדכני של קוד המקור ואת הערות התחזוקה](https://github.com/QuanuX/Symphony#readme) ואת המפרט של כל מודול שבחרתם לפני שאתם מפעילים אותו.
