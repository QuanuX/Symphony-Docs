يحكم متجه عقود API في Symphony ‏(SACV) عقود API ذات الإصدارات عبر المنصة. ومحركه عملية C++ قابلة للتثبيت بشكل مستقل تُجري تحققًا محدودًا من JSON وفق OpenAPI 3.2.0، وفروقات توافق حتمية، وعمليات جرد مؤقتة. تبقى دلالات نقاط النهاية لدى المتجه أو الوحدة المالكة للنطاق؛ أما SACV فيحكم شكل العقد وتوافقه.

## العمليات

- **الفحص والتحقق**: التحقق من أن مستند JSON وفق OpenAPI 3.2.0 يطابق ملف التعريف المحدود.
- **المقارنة (Diff)**: حساب فروقات توافق حتمية بين إصدارات العقود.
- **الاقتراح**: قبول مقترحات السجل التي يصرّح بها المستدعي للعقود الجديدة أو المعدّلة.
- **الإسقاط**: إصدار عمليات جرد مؤقتة للمراجعين والأدوات اللاحقة.

## ما يحكمه SACV

يقيّد SACV ما يلي:

- شكل العقد (OpenAPI 3.2.0 مع ملف تعريف SACV)
- تصنيف التوافق بين الإصدارات
- عضوية السجل للعقود المقبولة

وهو لا:

- يملك دلالات نقاط النهاية (يحتفظ بها كل متجه أو وحدة)
- يولّد حزم SDK أو ينشر مخرجات أو يصدر رموزًا مميزة (tokens)
- يوحي بوجود واجهة شبكية حية (ذكر واجهة API خاصة مستقبلية لا ينشئها)

<Note>
  SACV مخصص للقراءة والاستعلام والتحقق والاقتراح فقط. التطبيق القانوني البرمجي معطّل عبر محركات SKV.
</Note>
