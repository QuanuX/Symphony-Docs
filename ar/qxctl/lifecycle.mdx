تدير قواعد الأوامر `qxctl knowledge lifecycle ...` ملفات التعريف المحمية، والملكية، والملاحظات، وسجلات الإقلاع، والانتقالات المتوافقة مع التطبيق. كل تعديل هو عملية مقارنة ومبادلة (compare-and-swap)، وكل عملية تطبيق مقيّدة بأدلة دقيقة.

## ملف التعريف

اضبط ملف تعريف دورة الحياة المحمي لـ TOPS:

```bash Profile compare-and-swap
qxctl knowledge lifecycle profile set \
  --tops-id UUID \
  --input FILE \
  --expected-profile-digest absent|DIGEST
```

مرّر `absent` لملف تعريف يُنشأ لأول مرة، أو الملخص الدقيق الذي أبلغت عنه قراءة سابقة.

## الملكية

- `ownership status`: فحص جذر مشترك واحد مُكوَّن
- `ownership reconcile`: تحديث أدلته
- `ownership adopt`: التبنّي فقط بعد مراجعة كل مطالبة قديمة متحفظة
- `ownership release`: التحرير فقط لإيصال قديم واحد محدد جُعل قابلًا للاستعادة عمدًا

<Warning>
  لا تحذف أبدًا السجل المحلي للجذر أو حاجز توافق تخطيط الإيصالات `symphony-root-ownership/1` الخاص به، ولا تُعِد كتابتهما يدويًا. يجب أن تصادف عملاء دورة الحياة الأقدم ذلك الحاجز وتتوقف عند عائق الحزمة غير المعروفة الموجود لديها.
</Warning>

## المراقبة والتقرير والإقلاع

- `observe`: إصدار أدلة إيصال مؤقتة ذات تخطيط ثابت
- `report`: إنتاج خطة مؤقتة جديدة
- `boot`: تقدّم دائم للتقارير فقط مع معرّف عملية مستقر وحالة سجل دقيقة
- `status`: فحص v1
- `recover --discover`: استرداد سلسلة v1 فريدة عندما يتعذر على الحالة العادية التحقق من الحالة المحلية

## ملفات التعريف المتوافقة مع التطبيق

بالنسبة لملف تعريف `apply-compatible`، استدعِ `apply` فقط مع ملخص مصدر الإقلاع الدقيق، والمقارنة والمبادلة لسجل التطبيق، والمقارنة والمبادلة للحالة المطبّقة، ومعرّف عملية مستقر، وجذور مرحلية صريحة:

```bash Apply
qxctl knowledge lifecycle apply \
  --tops-id UUID \
  --operation-id OPID \
  --boot-source-digest DIGEST \
  --expected-apply-journal-digest DIGEST \
  --expected-applied-state-digest DIGEST \
  --staged-root PATH
```

استخدم `apply-status` لمراقبة المحاولات، أو `apply-recover` المحدود للاسترداد الدائم. لا تختر إجراءً يدويًا أبدًا ولا تعدّل الحالة المحمية.

<Note>
  يجب أن يغيّر تحديث الملاحظة الذي يقتصر على الطابع الزمني أدلةَ المستند دون تقديم الهويات الدلالية المستقرة.
</Note>
