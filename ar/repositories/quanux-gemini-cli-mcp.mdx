يحتوي هذا المستودع على امتداد Gemini CLI لتطبيق QuanuX السابق. يصف ملف README الخاص به تحميل سياق GEMINI.md، وإنشاء حزم استراتيجيات Python داخل server/strategies، والتحقق من حالة محرك وقت التشغيل.

## تقييم الشيفرة المصدرية {#source-evaluation}

يصف المستودع اعتماديات Python وكيفية ربط الامتداد بـ Gemini CLI. اقرأ ملف README الحالي وملفات الاعتماديات، وراجع الامتداد، واختبره مع لقطة التطبيق المطابقة في مساحة عمل معزولة.

## العلاقة بـ Symphony {#relationship-to-symphony}

هذا المشروع مختلف عن عميل Symphony التجريبي الأصلي، ولا يثبت التوافق مع مجموعة الحزم الموقّعة 0.2.0-beta.1. للحصول على عميل Symphony المؤهل الحالي، استخدم [تنزيلات النسخة التجريبية وإعداد العميل](https://quanux.org/downloads). تعامل مع مسارات التطبيق القديم وأمثلة الأوامر على أنها خاصة بهذا المستودع، لا على أنها عقود عامة لـ Symphony.
