يحتوي هذا المستودع العام على لقطة سابقة من تطبيق QuanuX الكمي، مع هدف إصدار تمهيدي v0.0.1-pre. يصف ملف README الخاص به خادم Python وأدوات عميل Node/pnpm ومسار تطوير لسطح المكتب باستخدام Tauri.

## افصل بين الإصدارات {#keep-the-releases-distinct}

تنتمي حزمة Conda السابقة quanux وتعليمات إعداد التطبيق إلى هذه اللقطة. وهي ليست طريقة تثبيت Symphony Public Beta 0.2.0-beta.1.

لإصدار Symphony الأصلي الحالي، استخدم [تنزيلات Symphony وملفات تعريف Anaconda الدقيقة](https://quanux.org/downloads) و[دليل اختبار النسخة التجريبية](https://quanux.org/beta).

## استكشف اللقطة {#explore-the-snapshot}

استخدم ملف README والترخيص وملفات بيان الاعتماديات ومراجعة الشيفرة المصدرية المسجلة لهذا المستودع عند دراسة بنيته أو إعادة إنتاج سلوكه التاريخي. يجب عدم ترقية واجهات API التجريبية ونموذج التطبيق الخاصين به بصمت إلى بنية Symphony الحالية أو إلى ادعاءات الجاهزية.
