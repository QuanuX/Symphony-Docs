يملك المتجه الكمي في Symphony ‏(SQV) عقود أطر قابلة لإعادة الاستخدام للبحث الكمي، وبناء أنظمة التداول، ودعم التنفيذ، والمحركات الكمية اللاحقة. ويبقى منطق الاستراتيجية ملكًا لك دائمًا. يوفر SQV واجهات الإطار وأدلة التوافق الدقيقة، لكنه لا يحدد أبدًا أدواتك المالية أو مصادر بياناتك أو اشتراكاتك أو منطق أوامرك أو نموذج التنفيذ لديك.

## حدود استراتيجية المستخدم

تحتفظ بالملكية الكاملة لمنطق الاستراتيجية. فلا يقوم SQV بما يلي:

- اختيار أدواتك المالية أو مصادر بياناتك
- تحديد حقول الاشتراك أو عمق السوق
- تحديد سلوك الفشل أو قواعد التسوية المعيارية
- كتابة منطق الأوامر أو نماذج التنفيذ
- تصميم بنيتك المعيارية الداخلية

تقدم Symphony أدلة التوافق والعمليات المدعومة. ولا ترتّب الاستراتيجيات أبدًا ولا تفرض قانون المنصة على قرارات التداول الخاصة بك.

## SOOV: متجه Symphony Orchestra Omega

SOOV هو أول متجه فرعي مسمّى ضمن SQV. ويمثل بنية FIX مستقبلية عالية الأداء مبنية بلغة C++ فقط ومستندة إلى أعمال QuanuX السابقة. ومن المخطط أن يكون SOOV طبقة مراسلة محدودة وحتمية لاتصالات التداول. لم يصبح سلوك FIX التفصيلي قانونيًا بعد؛ ولا يوجد حاليًا أي تنفيذ لجلسة FIX أو محوّل مصدر بيانات أو تكامل مع وسيط.

## النطاق المستقبلي

SQV هو الموطن المخطط لمكونات الإطار الكمي المُقرّة عبر مراحل التسليم اللاحقة. وتشمل المجالات المتوقعة:

- محركات الاختبار الرجعي
- واجهات C++ API للوسطاء
- مكتبات المؤشرات
- الرياضيات الكمية
- بنية تدفقات البيانات

لن يُنفَّذ أيٌّ منها حتى تُقرّ عقوده الخاصة.

## الحالة الحالية

SQV عقد معماري قانوني فقط. لا يوجد حاليًا أي تنفيذ لمحرك SQV أو SOOV، أو جلسة FIX، أو محوّل مصدر بيانات، أو بيئة تشغيل للاستراتيجيات، أو تكامل مع وسيط، أو أداة اختبار رجعي، أو مكتبة مؤشرات، أو مكون لتدفق البيانات.
