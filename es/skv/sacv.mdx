El Symphony API Contract Vector (SACV) gobierna los contratos de API versionados en toda la plataforma. Su motor es un proceso en C++ instalable de forma independiente que realiza validación acotada de JSON OpenAPI 3.2.0, diferencias de compatibilidad deterministas e inventarios desechables. La semántica de los endpoints sigue perteneciendo al vector o módulo propietario del dominio; SACV gobierna la forma y la compatibilidad de los contratos.

## Operaciones

- **Inspeccionar y comprobar**: valida que un documento JSON OpenAPI 3.2.0 se ajuste al perfil acotado.
- **Diff**: calcula diferencias de compatibilidad deterministas entre versiones de contratos.
- **Proponer**: acepta propuestas de registro declaradas por quien llama para contratos nuevos o modificados.
- **Proyectar**: emite inventarios desechables para revisores y herramientas posteriores.

## Qué gobierna SACV

SACV acota:

- La forma del contrato (OpenAPI 3.2.0 con el perfil de SACV)
- La clasificación de compatibilidad entre versiones
- La pertenencia al registro de los contratos aceptados

No:

- Es propietario de la semántica de los endpoints (cada vector o módulo la conserva)
- Genera SDK, publica artefactos ni emite tokens
- Implica que exista una superficie de red activa (mencionar una futura API privada no la crea)

<Note>
  SACV es únicamente de lectura, consulta, validación y propuesta. La aplicación canónica programática está desactivada en todos los motores SKV.
</Note>
