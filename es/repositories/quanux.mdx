Este repositorio público contiene una instantánea anterior de la aplicación cuantitativa QuanuX, con un objetivo de prelanzamiento v0.0.1-pre. Su README describe un servidor en Python, herramientas de cliente con Node/pnpm y una ruta de desarrollo de escritorio con Tauri.

## Mantén las versiones separadas {#keep-the-releases-distinct}

El paquete Conda quanux anterior y las instrucciones de configuración de la aplicación pertenecen a esta instantánea. No son la vía de instalación de Symphony Public Beta 0.2.0-beta.1.

Para la versión nativa actual de Symphony, usa [las descargas de Symphony y los perfiles exactos de Anaconda](https://quanux.org/downloads) y [la guía de pruebas de la beta](https://quanux.org/beta).

## Explora la instantánea {#explore-the-snapshot}

Usa el README, la licencia, los manifiestos de dependencias y la revisión de código fuente registrada de este repositorio al investigar su arquitectura o reproducir su comportamiento histórico. Sus API experimentales y su modelo de aplicación no deben promoverse de forma silenciosa a la arquitectura actual de Symphony ni a afirmaciones de preparación.
