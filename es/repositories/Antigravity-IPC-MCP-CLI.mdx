Este proyecto proporciona superficies nativas de IPC local y MCP para Antigravity y otros flujos de trabajo de clientes de agentes, con soporte de CLI y configuración de conexión explícita.

## Qué evaluar {#what-to-evaluate}

- Revisa los requisitos de compilación de C++26 declarados y el contrato del protocolo.
- Inspecciona las opciones de transporte stdio e IPC local y sus límites de autoridad.
- Genera y revisa una configuración de cliente para el host previsto.
- Ejecuta las pruebas del repositorio antes de evaluar una sesión real de un cliente de agentes.

Las integraciones de Antigravity, agy, Gemini, Codex y Claude conservan sus propios requisitos de configuración y cualificación específicos de cada cliente. Este repositorio independiente es distinto del cliente Codex incluido en la distribución firmada de Symphony. No deduzcas la inclusión en la beta binaria ni la aprobación en directorios de terceros a partir de la disponibilidad del código fuente.
