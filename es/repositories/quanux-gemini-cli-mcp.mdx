Este repositorio contiene una extensión de Gemini CLI para la aplicación QuanuX anterior. Su README describe cómo cargar el contexto de GEMINI.md, generar paquetes de estrategias en Python en server/strategies y comprobar el estado del motor de ejecución.

## Evaluación del código fuente {#source-evaluation}

El repositorio describe las dependencias de Python y cómo vincular la extensión con Gemini CLI. Lee su README y sus archivos de dependencias actuales, revisa la extensión y pruébala con la instantánea de la aplicación correspondiente en un espacio de trabajo aislado.

## Relación con Symphony {#relationship-to-symphony}

Este proyecto es distinto del cliente beta nativo de Symphony y no establece compatibilidad con el conjunto de paquetes firmado 0.2.0-beta.1. Para el cliente de Symphony cualificado actual, usa [las descargas de la beta y la configuración del cliente](https://quanux.org/downloads). Trata las rutas de la aplicación heredada y los ejemplos de comandos como propios de este repositorio, no como contratos universales de Symphony.
