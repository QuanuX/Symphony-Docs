Este proyecto proporciona un puente MCP nativo en C++, catálogos de herramientas, generadores de configuración de clientes y skills para operaciones locales de Symphony mediante qxctl. Conserva el enrutamiento exacto a propietarios y la autoridad explícita.

## Empieza con el cliente beta {#start-with-the-beta-client}

Para la ruta binaria cualificada, usa el cliente incluido en [Symphony 0.2.0-beta.1](https://quanux.org/downloads). Sigue la [guía de conservación y configuración del cliente](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md). Codex es el cliente cualificado principal; los adaptadores de configuración existentes de Claude, Antigravity y genéricos conservan sus propios límites.

## Explorar {#explore}

- Descubre herramientas estructuradas y enruta operaciones a los propietarios de qxctl instalados.
- Genera un perfil de conexión aislado y un fragmento de configuración de cliente.
- Empieza con operaciones de lectura; habilita la autoridad de escritura solo mediante flujos de propietario documentados.
- Inspecciona las skills del proyecto y las instrucciones de compilación y prueba a nivel de código fuente.

El contrato del protocolo está fijado en este repositorio. Usa su versión declarada y sus requisitos previos de compilación en lugar de sustituirlos silenciosamente por una revisión de MCP más reciente. Un repositorio público o una configuración de cliente local no constituye una afirmación de aprobación en un directorio de plugins de terceros.
