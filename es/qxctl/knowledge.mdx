El grupo `qxctl knowledge ...` gestiona el ciclo de vida entre vectores y la administración persistente de sesiones SSFV. Es el punto de entrada para las operaciones respaldadas por el coordinador y para las consultas de invariantes contra el validador.

## Transición de sesión

Usa `qxctl knowledge session transition` para señalar un evento del ciclo de vida del host a una sesión existente:

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

Los reintentos seguros reutilizan el mismo ID de evento. Añade `--recover` solo cuando se pretenda una recuperación por descubrimiento a partir de evidencia de sesión local dañada; no recupera denegaciones, estados críticos incompatibles ni ambigüedades.

<Warning>
  Symphony no instala ningún hook de inicio de sesión, observador ni unidad de arranque mediante este comando. Úsalo solo cuando una integración explícita con el ciclo de vida del host proporcione una identidad de evento estable.
</Warning>

## Consultas de invariantes

Cuatro comandos hoja vinculan `ssfv:symphony:qxctl.invariant-assurance`:

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` vincula además `ssfv:symphony:symphony-validator.invariant-ownership-assurance`.

Los comandos hoja de consulta directa emiten `symphony.knowledge.invariant-query-result.v1` con `semantic_validity=not_asserted`. `check` devuelve el resultado completo y exacto del validador y conserva el código de salida 26.
