`qxctl validate ...` 語法用於管理 Symphony 驗證器受保護的警告政策、基準與顯示語法。獨立安裝的 C++ 驗證器會產生不可變的原始證據；qxctl 則管理呼叫者中立的受保護呈現方式，且不會變更偵測結果。

## qxctl validate 涵蓋的範圍

- 九個受保護的警告生命週期葉節點命令
- 確切的收據支援根摘要路由
- 基準管理與差異報告
- 行輸出與結構化 JSON 的顯示語法

每個葉節點命令在套用受保護的警告政策之前，都會驗證驗證器的確切收據與結構化摘要。

## 邊界

<Warning>
  qxctl validate 無法修復檔案、發布任何內容，或覆寫原始偵測器證據。警告處置影響的是呈現方式，而非偵測結果。
</Warning>

- 不得在受保護政策之外抑制警告
- 不得修改驗證器輸出
- 不得為無法使用的路由捏造涵蓋範圍

## 常見用途

- 建立或重設警告基準
- 核准或重新開啟受治理的歷史警告
- 輸出出現在儲存庫 README 中的收據支援根摘要

支撐此語法的驗證器會檢查合約結構、目前原始碼封閉性、不變式擁有權、功能管理、版本發布，以及機器擁有的根摘要。
