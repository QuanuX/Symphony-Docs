Symphony 雲端向量（Symphony Cloud Vector，SCV）擁有關於異地硬體資源，以及影響你的叢集、訓練、研究與資料工作之供應商實際情況的私有語意知識。它會對應供應商的產品、區域、基礎架構網域、限制條件與觀察到的可用性，但不會為供應商排名，也不會限制你可以嘗試的事情。

## 供應商涵蓋範圍

SCV 涵蓋以下供應商與資源類型：

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- 使用者自有硬體（在需要與異地資源比較時）

## 可攜式供應商套件與組合

SCV 透過 qxctl 提供可攜式供應商套件。你仍可掌控需求、供應商權限、配方替代方案與執行決策。qxctl 支援保留的工作流程與受保護的圖形選擇，因此你可以重播確切的證據，而無須重新查詢供應商。

## 選用的 DuckDB 連接器

`scv-graph-duckdb-connector` 為不可變的原生圖形新增有界的關聯式投影。DuckDB 是使用者選擇的預設 SQL 資料庫。未來你可以透過額外的配接器選擇專用的圖形引擎。

## 隱私與主權

已安裝的 SCV 知識圖屬於你的私有安裝。使用者提供的帳戶、餘額、權限與合約限制，只會透過明確啟用的觀察介面使用。私有事實不會進入 Symphony 官方的來源真相。

## 具版本的介面增量

SCV 版本發布採累加式且具確切版本。較早的安裝仍可在其確切範圍內呼叫。目前的增量包括原生操作、語料庫快照、解讀設定檔、可攜式供應商套件、組合工作流程、義務追蹤與證據組合包。每個增量都會保留先前的路由、預設值與紀錄。
