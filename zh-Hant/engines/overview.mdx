每個作用中的應用程式層級 Symphony vector 都可以擁有一個可獨立安裝、在程序外執行的 C++ 引擎。共用且不具權限的 C++ 機制位於 `libraries/` 之下；另有一個獨立的 C++ 協調器負責經驗證的工作階段與工作樹協調機制。引擎會在 vector 擁有的合約範圍內進行檢查、驗證、投影與提案。它們不會僅因產生內容就取得權限。

## SKV 引擎系列

每個 SKV 介面都有自己的引擎：

- SKVI、SCLV、SACV、SODV 與 SSFV 引擎各自實作 inspect、check、propose、project（以及適用時的 recovery）。
- SAV 與 SEV 引擎是凍結路徑的 C++26 程序，用於組合評估與演進案例。

<Note>
  目前所有 SKV 引擎都僅支援讀取、查詢、驗證與提案。在每個引擎的 SSIAG 權限驗證、預期狀態交易、qxctl 防護措施、STAV 事件、復原與負面測試合約完成之前，程式化的標準套用仍維持停用。
</Note>

## 共通保證

- 每個模組皆可獨立安裝與解除安裝
- 不進行周遭儲存庫爬梳；資訊清單探索是明確的
- 沒有共用權限；每條變更路由都受 SSIAG 與 STAV 把關
- 不常駐於熱路徑；引擎絕不會為即時工作負載帶來延遲
