Symphony 是依據 Vector-Graph Application Architecture 開發的開放原始碼 quantOS。原生引擎與 SDK 負責領域工作；qxctl 為代理與人員提供共同的控制介面。使用者可自行選擇引擎、策略、供應商與拓撲。

## 公開測試版 {#public-beta}

已發布的版本為 **0.2.0-beta.1**，於 2026 年 11 月 16 日推出。它為每個確切設定檔提供 59 個預設套件、一個原生 Codex 用戶端、SDK 匯出以及選用的對應原始碼。

| 目標 | 架構 |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

請從[下載與 Anaconda 說明](https://quanux.org/downloads)開始，接著使用[測試版功能與測試指南](https://quanux.org/beta)。

## 可探索的功能 {#capabilities-to-explore}

- qxctl 資訊清單、版本、已安裝擁有者檢查以及明確管理。
- SQV 擷取、中繼資料、資料流、整數轉換、本機儲存區、重播與檢查點。
- SBV 範圍受限的回測研究、普查、原生評估、保留結果、取消與復原。
- SHV 以來源為依據的硬體目錄、需求、圖形與發布預覽。
- SCV 供應商知識，以及 SNV Node 身分、資源、叢集關係與命名。
- SSIAG 授權、STAV 稽核證據、組合以及知識治理。

## 資格認證界線 {#qualification-boundaries}

發布紀錄會標示經過認證的確切位元組。實體 DGX Spark、GPU 行為與正式環境供應商部署需要個別的證據。一般憑證傳遞與原生供應商橋接器有明確列出的實作缺口；安裝轉接器並不代表已認證正式環境連線。原始碼主要分支上的修正無法取代已簽署的測試版成品。

在運作所選模組之前，請閱讀[目前的原始碼 README 與維護說明](https://github.com/QuanuX/Symphony#readme)以及每個所選模組的規格。
