此儲存庫包含一個適用於早期 QuanuX 應用程式的 Gemini CLI 擴充功能。其 README 說明如何載入 GEMINI.md 內容、在 server/strategies 中產生 Python 策略套件，以及檢查執行階段引擎狀態。

## 原始碼評估 {#source-evaluation}

此儲存庫說明了 Python 相依套件，以及如何將擴充功能連結至 Gemini CLI。請閱讀其目前的 README 與相依性檔案，檢視擴充功能，並在隔離的工作區中使用對應的應用程式快照進行測試。

## 與 Symphony 的關係 {#relationship-to-symphony}

此專案與 Symphony 的原生測試版用戶端不同，也不保證與已簽署的 0.2.0-beta.1 套件集相容。如需目前經過認證的 Symphony 用戶端，請使用[測試版下載與用戶端設定](https://quanux.org/downloads)。請將舊版應用程式的路徑與命令範例視為此儲存庫特有的內容，而非通用的 Symphony 合約。
