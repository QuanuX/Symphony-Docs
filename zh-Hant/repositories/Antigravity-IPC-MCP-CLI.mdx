此專案為 Antigravity 及其他代理用戶端工作流程提供原生本機 IPC 與 MCP 介面，並支援 CLI 與明確的連線設定。

## 需要評估的項目 {#what-to-evaluate}

- 檢視宣告的 C++26 建置需求與通訊協定合約。
- 檢查 stdio 與本機 IPC 傳輸選項及其權限界線。
- 為目標主機產生並檢視用戶端設定。
- 在評估實際的代理用戶端工作階段之前，先執行儲存庫的測試。

Antigravity、agy、Gemini、Codex 與 Claude 整合各自保留其用戶端專屬的設定與資格認證需求。這個獨立儲存庫與已簽署 Symphony 發行版中隨附的 Codex 用戶端不同。請勿因為原始碼公開可用，就推斷它已納入二進位測試版，或已在第三方目錄中獲得核准。
