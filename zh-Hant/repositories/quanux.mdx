此公開儲存庫包含早期 QuanuX 量化應用程式的快照，預發布目標版本為 v0.0.1-pre。其 README 說明了 Python 伺服器、Node/pnpm 用戶端工具，以及使用 Tauri 的桌面開發路徑。

## 區分不同的版本 {#keep-the-releases-distinct}

早期的 quanux Conda 套件與應用程式設定說明屬於此快照。它們不是 Symphony Public Beta 0.2.0-beta.1 的安裝方式。

如需目前的原生 Symphony 版本，請使用[Symphony 下載與確切的 Anaconda 設定檔](https://quanux.org/downloads)以及[測試版測試指南](https://quanux.org/beta)。

## 探索快照 {#explore-the-snapshot}

研究其架構或重現歷史行為時，請使用此儲存庫的 README、授權、相依性資訊清單與記錄的原始碼修訂版本。不得將其實驗性 API 與應用程式模型悄悄納入目前的 Symphony 架構或就緒性主張。
