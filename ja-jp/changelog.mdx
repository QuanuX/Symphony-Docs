## 新機能

- **Symphony Node Vector エンジン。** 個別にインストール可能な 5 つの C++26 エンジンが、Node の識別情報（SNIV）、リソース（SNRV）、クラスター関係（SCIV）、名前（SCNV）、および SNV の構成と保持をカバーするようになりました。提供されたエビデンス、選択したビュー、保持された履歴を qxctl から管理できます。ライブ観測と SOV プロビジョニングはまだ含まれていません。[Node Vector](/ja-jp/vectors/snv) を参照してください。
- **オプションの SNV ローカルオブザーバー。** qxctl は、選択した CPU とメモリの観測結果を明示的な不確実性とともに報告する独立したローカルオブザーバーを呼び出せます。オブザーバーが識別情報、メンバーシップ、名前を割り当てることはありません。
- **SQV リサーチデータ基盤。** 新しい C++26 ライブラリが、元のバイト列とソースの来歴を保持したキャプチャ（SQAV）、メタデータ（SQMV）、フロー（SQFV）をカバーします。また、リネージ付きの厳密な整数変換（SQTV）、ローカル保持（SQPV）、チェックポイントと厳密な再開を備えた配信（SQDV）もカバーします。[Quantitative Vector](/ja-jp/vectors/sqv) を参照してください。
- **qxctl による SQV の管理。** 個別にインストール可能な 7 つの管理エンジンが、リクエストと設定の検証、メタデータのプロジェクション、保持状態の読み取り専用インスペクションを提供します。[Vector コマンド](/ja-jp/qxctl/vector-commands) を参照してください。
- **Databento およびブローカーアダプター。** SQV は Databento DBNv3 MBO のキャプチャをサポートし、DBNv1 と DBNv3 のサンプルを保持し、カバレッジのエビデンスとともに範囲を限定した過去データリクエストを計画するようになりました。非ライブのソースおよびブローカー読み取りアダプターも利用できます。認証付きのプロバイダー実行とライブ収集は今後の課題です。

## アップデート

- **SSIAG のクレデンシャル受け入れ。** SSIAG に、ワンショットのクレデンシャル使用ガード、認証済みディスパッチの受け入れ、リカバリー機能付きの永続的なクレデンシャルリクエストジャーナル、macOS でのネイティブなピア検証が追加されました。運用でのクレデンシャル使用は引き続き無効です。[SSIAG](/ja-jp/governance/ssiag) を参照してください。
- **qxctl のコマンドカバレッジ。** qxctl の安定したコマンド ID は 383 から 399 に増えました。エンジンバインディングは、5 つの SNV エンジンを含む 13 の確立されたロールをサポートします。[qxctl の概要](/ja-jp/qxctl/overview) を参照してください。
- **SQFV バッチインターフェース。** SQFV バッチライブラリは C ABI ではなく C++26 API を使用するようになりました。以前のインターフェースを呼び出していた統合はすべて更新してください。
- **SKVI の対応範囲。** [SKVI](/ja-jp/skv/skvi) は、新しい SQV リサーチデータのオーナーを含む、より多くのサーフェスをインデックス化します。
- **エンジンのインストールガイダンス。** インストールガイダンスで、各エンジンを個別にインストール、更新、削除することが明確になりました。[エンジンの概要](/ja-jp/engines/overview) を参照してください。
