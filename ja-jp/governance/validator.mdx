Symphony Validator（`tools/symphony-validator`）は、独立した、決定論的で読み取り専用の C++26 リポジトリチェッカーです。リポジトリとそのコントラクトの現在の状態について、不変のエビデンスを生成します。何かを修復したり公開したりすることはできません。

## バリデーターがチェックするもの

- コントラクトの形状: 必須の Contract Quad のアンカーと構造
- SKVI でインデックス化されたサーフェス全体にわたる現在のソースのクロージャー
- `knowledge/INVARIANTS.md` と不変条件レジストリに基づく不変条件の所有権
- SSFV が報告する機能管理の期待値
- SODV が報告するリリースレコード
- リポジトリの README にある、機械が所有するルートサマリー

エビデンスは、行形式の出力または構造化 JSON として出力されます。すべての出力は、同じリポジトリの状態から再現可能です。

## バリデーターが行わないこと

<Warning>
  バリデーターは、ファイルを修復したり、コントラクトを書き換えたり、リポジトリを公開したりすることはできません。正規の真実を何ひとつ作り出すことはなく、報告するだけです。
</Warning>

- リポジトリへの副作用はありません
- ネットワークアクセスはありません
- qxctl の保護された警告ポリシー以外で警告が抑制されることはありません

## qxctl との統合

qxctl は、保護された警告ポリシーを適用する前に、バリデーターの厳密なレシートと構造化ダイジェストを検証します。保護された警告ライフサイクルを扱う 9 つの qxctl リーフコマンドと、レシートに裏付けられた厳密なルートサマリーのルートにより、生の検出結果のエビデンスを変更することなく検証の管理機能が提供されます。
