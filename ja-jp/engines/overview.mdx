アクティブなアプリケーションレベルの Symphony ベクターには、それぞれ個別にインストール可能なプロセス外の C++ エンジンを用意できます。権限を持たない共有 C++ メカニズムは `libraries/` 配下にあり、別個の C++ コーディネーターが認証済みセッションとワークツリー調整のメカニズムを所有します。エンジンは、ベクターが所有するコントラクトの範囲内で検査、検証、プロジェクション、提案を行います。コンテンツを生成しただけで権限を得ることはありません。

## SKV エンジンファミリー

SKV の各サーフェスには、それぞれ専用のエンジンがあります。

- SKVI、SCLV、SACV、SODV、SSFV の各エンジンは、inspect、check、propose、project（および該当する場合は recovery）を実装します。
- SAV と SEV のエンジンは、構成の評価と進化のケースを扱うフリージングパスの C++26 プロセスです。

<Note>
  現在のすべての SKV エンジンは、読み取り、クエリ、検証、提案のみを行います。プログラムによる正規の適用は、各エンジンの SSIAG 権限検証、期待状態トランザクション、qxctl セーフガード、STAV イベント、リカバリー、ネガティブテストの各コントラクトが完成するまで無効のままです。
</Note>

## 共通の保証

- モジュールごとの個別のインストールとアンインストール
- リポジトリ全体の暗黙的なクロールはなく、マニフェスト探索は明示的
- 権限の共有はなく、変更を伴うすべてのルートは SSIAG と STAV によって制御
- ホットパスへの常駐はなく、エンジンがライブワークロードにレイテンシーを持ち込むことはない
