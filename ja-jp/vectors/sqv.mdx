Symphony Quantitative Vector（SQV）は、クオンツリサーチ、トレーディングシステムの構築、執行サポート、および今後のクオンツエンジンのための再利用可能なフレームワークコントラクトを所有します。戦略ロジックは常にあなたのものです。SQV はフレームワークサーフェスと正確な互換性エビデンスを提供しますが、あなたの銘柄、フィード、サブスクリプション、注文ロジック、執行モデルを決定することは決してありません。

## ユーザー戦略の境界

戦略ロジックの所有権はすべてあなたが保持します。SQV は次のことを行いません:

- 銘柄やデータフィードを選択する
- サブスクリプションのフィールドやマーケットデプスを定義する
- 障害時の挙動や正規化ルールを決定する
- 注文ロジックや執行モデルを記述する
- 内部のモジュール構造を設計する

Symphony は互換性エビデンスとサポート対象の操作を提供します。戦略をランク付けしたり、トレーディングの判断にプラットフォームの規則を課したりすることは決してありません。

## SOOV: Symphony Orchestra Omega Vector

SOOV は、SQV のもとにある最初の名前付きサブベクターです。過去の QuanuX の取り組みに基づいた、将来の高性能な C++ 専用 FIX アーキテクチャを表します。SOOV は、トレーディング通信のための範囲限定で決定論的なメッセージングレイヤーとして計画されています。詳細な FIX の挙動はまだ正規ではなく、FIX セッション、フィードアダプター、ブローカー統合は現在いずれも実装されていません。

## 将来のスコープ

SQV は、今後のデリバリーフェーズにわたって、承認されたクオンツフレームワークコンポーネントを収める予定の場所です。想定される領域には次のものがあります:

- バックテストエンジン
- ブローカーの C++ API
- インジケーターライブラリ
- クオンツ数学
- データストリームアーキテクチャ

これらはいずれも、それぞれのコントラクトが承認されるまで実装されません。

## 現在のステータス

SQV は正規のアーキテクチャコントラクトのみです。SQV または SOOV のエンジン、FIX セッション、フィードアダプター、戦略ランタイム、ブローカー統合、バックテスター、インジケーターライブラリ、データストリームコンポーネントは、現在いずれも実装されていません。
