Symphony Cloud Vector（SCV）は、オフサイトのハードウェアリソースと、クラスター、トレーニング、リサーチ、データ作業を形作るプロバイダーの実情に関するプライベートなセマンティック知識を所有します。プロバイダーをランク付けしたり、あなたが試みてよいことに制限を課したりすることなく、プロバイダーの提供内容、リージョン、インフラストラクチャドメイン、制約、観測された可用性をマッピングします。

## プロバイダーのカバレッジ

SCV は次のプロバイダーとリソースタイプをカバーします:

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- ユーザー所有のハードウェア（オフサイトリソースとの比較が必要な場合）

## ポータブルなプロバイダーパッケージと構成

SCV は qxctl を通じてポータブルなプロバイダーパッケージを公開します。要件、プロバイダーの権限、レシピの代替案、実行の決定は、あなたが引き続き管理します。qxctl は保持されたワークフローと保護されたグラフ選択をサポートしているため、プロバイダーに再クエリすることなく正確なエビデンスを再生できます。

## オプションの DuckDB コネクター

`scv-graph-duckdb-connector` は、不変のネイティブグラフの範囲限定のリレーショナルプロジェクションを追加します。DuckDB はユーザーが選択したデフォルトの SQL データベースです。将来的には、追加のアダプターを通じて専用のグラフエンジンを選択できるようになります。

## プライバシーと主権

インストールされた SCV ナレッジグラフは、あなたのプライベートなインストールに属します。ユーザーが提供するアカウント、残高、権限、契約上の制約は、明示的に有効化された観測サーフェスを通じてのみ使用されます。プライベートな事実が Symphony の公式なソースの真実に入ることはありません。

## バージョン管理されたインターフェースのインクリメント

SCV のリリースは追加的で、正確にバージョン管理されています。以前のインストールは、その正確なスコープで引き続き呼び出し可能です。現在のインクリメントには、ネイティブ操作、コーパススナップショット、解釈プロファイル、ポータブルなプロバイダーパック、構成ワークフロー、義務の追跡、エビデンスバンドルが含まれます。各インクリメントは、以前のルート、デフォルト、記録を保持します。
