Ce dépôt public contient un ancien instantané de l'application quantitative QuanuX, avec une cible de préversion v0.0.1-pre. Son README décrit un serveur Python, des outils client Node/pnpm et un parcours de développement de bureau avec Tauri.

## Distinguer les versions {#keep-the-releases-distinct}

L'ancien paquet Conda quanux et les instructions de configuration de l'application appartiennent à cet instantané. Ils ne constituent pas la méthode d'installation de Symphony Public Beta 0.2.0-beta.1.

Pour la version native actuelle de Symphony, utilisez [les téléchargements de Symphony et les profils Anaconda exacts](https://quanux.org/downloads) ainsi que [le guide de test de la bêta](https://quanux.org/beta).

## Explorer l'instantané {#explore-the-snapshot}

Utilisez le README, la licence, les manifestes de dépendances et la révision du code source enregistrée de ce dépôt pour étudier son architecture ou reproduire son comportement historique. Ses API expérimentales et son modèle d'application ne doivent pas être promus silencieusement dans l'architecture actuelle de Symphony ni dans des affirmations de préparation.
