Ce projet fournit un pont MCP natif en C++, des catalogues d'outils, des générateurs de configuration client et des skills pour les opérations locales de Symphony via qxctl. Il préserve le routage exact vers les propriétaires et l'autorité explicite.

## Commencer avec le client bêta {#start-with-the-beta-client}

Pour le parcours binaire qualifié, utilisez le client fourni avec [Symphony 0.2.0-beta.1](https://quanux.org/downloads). Suivez le [guide de conservation et de configuration du client](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md). Codex est le principal client qualifié ; les adaptateurs de configuration existants pour Claude, Antigravity et génériques conservent leurs propres limites.

## Explorer {#explore}

- Découvrez des outils structurés et acheminez les opérations vers les propriétaires qxctl installés.
- Générez un profil de connexion isolé et un fragment de configuration client.
- Commencez par des opérations de lecture ; n'activez l'autorité d'écriture que via des flux de propriétaire documentés.
- Inspectez les skills du projet et les instructions de compilation et de test au niveau du code source.

Le contrat du protocole est épinglé dans ce dépôt. Utilisez sa version déclarée et ses prérequis de compilation plutôt que de les remplacer silencieusement par une révision MCP plus récente. Un dépôt public ou une configuration client locale ne constitue pas une revendication d'approbation dans un annuaire de plugins tiers.
