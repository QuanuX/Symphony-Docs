To repozytorium zawiera rozszerzenie Gemini CLI dla wcześniejszej aplikacji QuanuX. Jego README opisuje ładowanie kontekstu GEMINI.md, generowanie pakietów strategii w Pythonie w katalogu server/strategies i sprawdzanie stanu silnika środowiska wykonawczego.

## Ocena kodu źródłowego {#source-evaluation}

Repozytorium opisuje zależności Pythona i łączenie rozszerzenia z Gemini CLI. Przeczytaj jego aktualny README i pliki zależności, przejrzyj rozszerzenie i przetestuj je z odpowiadającą migawką aplikacji w izolowanym obszarze roboczym.

## Związek z Symphony {#relationship-to-symphony}

Ten projekt różni się od natywnego klienta beta Symphony i nie zapewnia zgodności z podpisanym zestawem pakietów 0.2.0-beta.1. W przypadku bieżącego zakwalifikowanego klienta Symphony skorzystaj z [pobierania wersji beta i konfiguracji klienta](https://quanux.org/downloads). Traktuj ścieżki starszej aplikacji i przykłady poleceń jako należące do tego repozytorium, a nie jako uniwersalne kontrakty Symphony.
