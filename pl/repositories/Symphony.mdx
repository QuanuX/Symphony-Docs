Symphony to open source'owy quantOS rozwijany zgodnie z Vector-Graph Application Architecture. Natywne silniki i SDK wykonują pracę dziedzinową; qxctl zapewnia agentom i ludziom wspólną powierzchnię sterowania. Użytkownicy wybierają własne silniki, strategie, dostawców i topologię.

## Publiczna wersja beta {#public-beta}

Opublikowane wydanie to **0.2.0-beta.1**, udostępnione 16 listopada 2026 r. Zawiera 59 pakietów domyślnych na dokładny profil, natywnego klienta Codex, eksporty SDK oraz opcjonalny odpowiadający kod źródłowy.

| Cel | Architektura |
| --- | --- |
| macOS 15 | Apple Silicon / ARM64 |
| Ubuntu 24.04 | AMD64 |
| Ubuntu 24.04 | ARM64 |
| Ubuntu 26.04 | AMD64 |

Zacznij od [pobierania i instrukcji Anacondy](https://quanux.org/downloads), a następnie skorzystaj z [przewodnika po możliwościach i testowaniu wersji beta](https://quanux.org/beta).

## Możliwości do poznania {#capabilities-to-explore}

- Manifesty qxctl, wersje, inspekcja zainstalowanych właścicieli i jawna administracja.
- Przechwytywanie, metadane, przepływ, konwersja na liczby całkowite, lokalne magazyny, odtwarzanie i punkty kontrolne SQV.
- Ograniczone badania backtestów, spis, natywna ocena, zachowane wyniki, anulowanie i odzyskiwanie SBV.
- Katalogi sprzętu oparte na źródłach, wymagania, grafy i podglądy publikacji SHV.
- Wiedza o dostawcach SCV oraz tożsamość Node, zasoby, relacje klastrów i nazewnictwo SNV.
- Autoryzacja SSIAG, dowody audytowe STAV, kompozycja i zarządzanie wiedzą.

## Granice kwalifikacji {#qualification-boundaries}

Rekord wydania identyfikuje dokładne zakwalifikowane bajty. Fizyczny DGX Spark, zachowanie GPU i wdrożenia produkcyjne u dostawców wymagają osobnych dowodów. Ogólne dostarczanie poświadczeń i natywne mosty do dostawców mają jawnie wskazane luki implementacyjne; zainstalowanie adaptera nie kwalifikuje połączenia produkcyjnego. Poprawki w gałęzi głównej kodu źródłowego nie zastępują podpisanych artefaktów beta.

Przeczytaj [aktualny README kodu źródłowego i uwagi dotyczące utrzymania](https://github.com/QuanuX/Symphony#readme) oraz specyfikację każdego wybranego modułu, zanim zaczniesz go używać.
