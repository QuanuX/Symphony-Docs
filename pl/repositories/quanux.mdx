To publiczne repozytorium zawiera wcześniejszą migawkę ilościowej aplikacji QuanuX z docelową wersją przedpremierową v0.0.1-pre. Jego README opisuje serwer w Pythonie, narzędzia klienta Node/pnpm oraz ścieżkę tworzenia aplikacji desktopowej w Tauri.

## Rozróżniaj wydania {#keep-the-releases-distinct}

Wcześniejszy pakiet Conda quanux i instrukcje konfiguracji aplikacji należą do tej migawki. Nie są one sposobem instalacji Symphony Public Beta 0.2.0-beta.1.

W przypadku bieżącego natywnego wydania Symphony skorzystaj z [pobierania Symphony i dokładnych profili Anacondy](https://quanux.org/downloads) oraz [przewodnika testowania wersji beta](https://quanux.org/beta).

## Poznaj migawkę {#explore-the-snapshot}

Korzystaj z README, licencji, manifestów zależności i zapisanej rewizji kodu źródłowego tego repozytorium, gdy badasz jego architekturę lub odtwarzasz historyczne działanie. Jego eksperymentalnych API i modelu aplikacji nie wolno po cichu przenosić do bieżącej architektury Symphony ani do twierdzeń o gotowości.
