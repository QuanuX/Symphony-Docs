Dieses Repository enthält eine Gemini-CLI-Erweiterung für die frühere QuanuX-Anwendung. Die README beschreibt das Laden des GEMINI.md-Kontexts, das Erzeugen von Python-Strategiepaketen in server/strategies und das Prüfen des Status der Runtime-Engine.

## Bewertung des Quellcodes {#source-evaluation}

Das Repository beschreibt die Python-Abhängigkeiten und das Verknüpfen der Erweiterung mit Gemini CLI. Lesen Sie die aktuelle README und die Abhängigkeitsdateien, prüfen Sie die Erweiterung und testen Sie sie in einem isolierten Workspace mit dem passenden Snapshot der Anwendung.

## Beziehung zu Symphony {#relationship-to-symphony}

Dieses Projekt unterscheidet sich vom nativen Beta-Client von Symphony und begründet keine Kompatibilität mit dem signierten Paketsatz 0.2.0-beta.1. Für den aktuell qualifizierten Symphony-Client nutzen Sie [die Beta-Downloads und die Client-Einrichtung](https://quanux.org/downloads). Betrachten Sie Pfade der Altanwendung und Befehlsbeispiele als zu diesem Repository gehörig, nicht als allgemeingültige Symphony-Verträge.
