Ce dépôt contient une extension Gemini CLI pour l'ancienne application QuanuX. Son README décrit le chargement du contexte GEMINI.md, la génération de paquets de stratégies Python dans server/strategies et la vérification de l'état du moteur d'exécution.

## Évaluation du code source {#source-evaluation}

Le dépôt décrit les dépendances Python et la liaison de l'extension avec Gemini CLI. Lisez son README et ses fichiers de dépendances actuels, examinez l'extension et testez-la avec l'instantané de l'application correspondant dans un espace de travail isolé.

## Relation avec Symphony {#relationship-to-symphony}

Ce projet est distinct du client bêta natif de Symphony et n'établit pas de compatibilité avec l'ensemble de paquets signé 0.2.0-beta.1. Pour le client Symphony qualifié actuel, utilisez [les téléchargements de la bêta et la configuration du client](https://quanux.org/downloads). Considérez les chemins de l'ancienne application et les exemples de commandes comme propres à ce dépôt, et non comme des contrats universels de Symphony.
