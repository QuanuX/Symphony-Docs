## 新功能

- **Symphony Node Vector 引擎。** 五个可独立安装的 C++26 引擎现已覆盖 Node 身份（SNIV）、资源（SNRV）、集群关系（SCIV）、名称（SCNV）以及 SNV 组合与留存。你可以通过 qxctl 管理所提供的证据、选定视图和留存历史。实时观测和 SOV 预配尚未包含在内。参见 [Node Vector](/zh-Hans/vectors/snv)。
- **可选的 SNV 本地观测器。** qxctl 可以调用一个独立的本地观测器，以明确的不确定性报告选定的 CPU 和内存观测结果。它从不分配身份、成员关系或名称。
- **SQV 研究数据基础。** 新的 C++26 库涵盖：保留原始字节和来源出处的采集（SQAV）、元数据（SQMV）、数据流（SQFV）、带血缘的精确整数转换（SQTV）、本地留存（SQPV），以及带检查点和精确续传的交付（SQDV）。参见 [Quantitative Vector](/zh-Hans/vectors/sqv)。
- **通过 qxctl 管理 SQV。** 七个可独立安装的管理引擎提供请求与配置校验、元数据投影以及只读的留存状态检查。参见 [Vector 命令](/zh-Hans/qxctl/vector-commands)。
- **Databento 与券商适配器。** SQV 现已支持 Databento DBNv3 MBO 采集，保留 DBNv1 和 DBNv3 样本，并能基于覆盖证据规划有界的历史请求。非实时数据源和券商读取适配器也已可用。经过身份验证的提供方执行和实时采集仍属于后续工作。

## 更新

- **SSIAG 凭据准入。** SSIAG 新增一次性凭据使用防护、经过身份验证的分派准入、支持恢复的持久化凭据请求日志，以及 macOS 上的原生对端校验。凭据的实际运营使用仍处于禁用状态。参见 [SSIAG](/zh-Hans/governance/ssiag)。
- **qxctl 命令覆盖范围。** qxctl 现有 399 个稳定的命令标识，此前为 383 个。引擎绑定支持 13 个既定角色，包括五个 SNV 引擎。参见 [qxctl 概览](/zh-Hans/qxctl/overview)。
- **SQFV 批处理接口。** SQFV 批处理库现在使用 C++26 API，而不再使用 C ABI。请更新所有调用旧接口的集成。
- **SKVI 容量。** [SKVI](/zh-Hans/skv/skvi) 可索引更多表面，包括新的 SQV 研究数据所有者。
- **引擎安装指南。** 安装指南现已明确：每个引擎都需单独安装、更新和移除。参见 [引擎概览](/zh-Hans/engines/overview)。
