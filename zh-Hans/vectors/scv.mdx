Symphony Cloud Vector（SCV，Symphony 云向量）拥有关于异地硬件资源以及影响你的集群、训练、研究和数据工作的提供商实际情况的私有语义知识。它映射提供商的产品、区域、基础设施域、约束以及观察到的可用性，而不对提供商进行排名，也不限制你可以尝试的事情。

## 提供商覆盖范围

SCV 涵盖以下提供商和资源类型：

- AWS
- Azure
- Google Cloud Platform
- DigitalOcean
- Cloudflare
- 用户自有硬件（在需要与异地资源进行比较时）

## 可移植的提供商包与组合

SCV 通过 qxctl 提供可移植的提供商包。你可以保留对需求、提供商权限、配方备选方案以及执行决策的控制权。qxctl 支持保留的工作流和受保护的图选择，因此你可以重放确切的证据，而无需重新查询提供商。

## 可选的 DuckDB 连接器

`scv-graph-duckdb-connector` 为不可变的原生图增加了有边界的关系型投影。DuckDB 是用户选定的默认 SQL 数据库。将来你可以通过额外的适配器选择专用的图引擎。

## 隐私与主权

已安装的 SCV 知识图属于你的私有安装。用户提供的账户、余额、权限和合同约束仅通过显式启用的观察界面使用。私有事实不会进入 Symphony 官方源事实。

## 带版本的接口增量

SCV 的版本发布是增量式且精确版本化的。较早的安装在其确切作用域内仍可调用。当前增量包括原生操作、语料快照、解释配置、可移植提供商包、组合工作流、义务跟踪以及证据包。每个增量都会保留之前的路由、默认值和记录。
