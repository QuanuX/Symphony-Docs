Symphony Ops Vector（SOV，Symphony 运维向量）是运维控制平面，经授权的 qxctl 命令通过它作用于你的基础设施。它拥有资源供给、Habitat 调整、Nest 交付、总线适配器设置以及可选的远程 Node 管理的契约。SOV 不会虚构提供商含义或硬件事实；它执行你已经选择的受支持选项。

## SOV 涵盖的内容

SOV 是一个新兴的第 2 阶段领域。其范围包括：

- **资源供给**：提供商与自有硬件的资源分配工作流
- **Habitat 调整**：向 Node 交付确切的操作系统和软件包配置
- **Nest 交付**：在 Node 上放置和更新工作负载
- **总线适配器建立**：通过你选择的总线（NATS JetStream、ZeroMQ 或其他）连接 Node
- **远程 Node 操作**：对本地 shell 之外的 Node 进行可选管理

<Note>
  提供商协议、Terraform 执行、Habitat 构建器、Nest 部署命令以及远程操作接收器仍有待设计。目前尚未实现任何 SOV 引擎或提供商变更。
</Note>

## qxctl 作为命令界面

SOV 操作通过 `qxctl` 提供，这是一个基于 Go、拥有 373 个可执行命令的管理 CLI。qxctl 实现并呈现 SOV 操作，但并不拥有其领域含义。向量拥有语义；工具拥有执行界面。

## 用户权限边界

由你选择提供商、区域、硬件、总线、软件、部署拓扑以及每个 Node 的管理安排。SOV 提供并执行受支持的选项。它不会对提供商进行排名、推荐拓扑，也不会将建议转化为强制性策略。

## 当前状态

SOV 是一份规范架构契约。目前不声称已实现任何引擎、Terraform 封装、Habitat 构建器、总线适配器或远程命令接收器。未来的 SOV 组件将在通用 SKV 生命周期下保持可独立安装、可按确切版本选择且可回滚。
