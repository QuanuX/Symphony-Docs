`qxctl knowledge ...` 命令组负责跨向量生命周期和持久化 SSFV 会话管理。它是由协调器支撑的操作以及针对验证器的不变量查询的入口。

## 会话转换

使用 `qxctl knowledge session transition` 向现有会话发送主机生命周期事件信号：

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

安全重试时请复用相同的事件 ID。仅当确实需要从损坏的本地会话证据中进行发现式恢复时才添加 `--recover`；它不会从拒绝、不兼容的关键状态或歧义中恢复。

<Warning>
  Symphony 不会通过此命令安装登录钩子、监视器或启动单元。仅当显式的主机生命周期集成提供了稳定的事件标识时才使用它。
</Warning>

## 不变量查询

以下四个叶命令绑定 `ssfv:symphony:qxctl.invariant-assurance`：

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` 还会额外绑定 `ssfv:symphony:symphony-validator.invariant-ownership-assurance`。

直接查询类叶命令会输出 `symphony.knowledge.invariant-query-result.v1`，并带有 `semantic_validity=not_asserted`。`check` 会返回验证器完整、确切的结果，并保留退出码 26。
