`qxctl validate ...` 语法用于管理 Symphony Validator 受保护的警告策略、基线和显示语法。独立安装的 C++ 验证器生成不可变的原始证据；qxctl 管理与调用方无关的受保护呈现方式，而不改变检测本身。

## qxctl validate 涵盖的内容

- 九个受保护的警告生命周期叶命令
- 确切的、由回执支撑的根摘要路由
- 基线管理与增量报告
- 行输出与结构化 JSON 的显示语法

每个叶命令在应用受保护的警告策略之前，都会验证验证器的确切回执和结构化摘要。

## 边界

<Warning>
  qxctl validate 不能修复文件、发布任何内容，也不能覆盖原始检测器证据。警告处置只影响呈现，不影响检测。
</Warning>

- 不允许在受保护策略之外抑制警告
- 不修改验证器输出
- 不为不可用的路由伪造覆盖率

## 常见用途

- 建立或重置警告基线
- 批准或重新开启受治理的历史警告
- 输出出现在仓库 README 中、由回执支撑的根摘要

支撑该语法的验证器会检查契约结构、当前源代码闭包、不变量所有权、功能管理、发布以及由机器拥有的根摘要。
