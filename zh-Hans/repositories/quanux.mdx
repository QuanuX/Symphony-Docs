该公开仓库包含早期 QuanuX 量化应用的快照，预发布目标版本为 v0.0.1-pre。其 README 介绍了 Python 服务器、Node/pnpm 客户端工具以及基于 Tauri 的桌面开发路径。

## 区分不同的版本 {#keep-the-releases-distinct}

早期的 quanux Conda 软件包和应用设置说明属于此快照。它们不是 Symphony Public Beta 0.2.0-beta.1 的安装方式。

如需当前的原生 Symphony 版本，请使用[Symphony 下载和确切的 Anaconda 配置文件](https://quanux.org/downloads)以及[测试版测试指南](https://quanux.org/beta)。

## 探索快照 {#explore-the-snapshot}

在研究其架构或复现历史行为时，请使用该仓库的 README、许可证、依赖清单和记录的源代码修订版本。不得将其实验性 API 和应用模型悄然纳入当前的 Symphony 架构或就绪性声明中。
