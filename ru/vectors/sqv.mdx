Symphony Quantitative Vector (SQV) владеет повторно используемыми контрактами фреймворка для количественных исследований, построения торговых систем, поддержки исполнения и будущих количественных движков. Логика стратегий всегда принадлежит вам. SQV предоставляет поверхности фреймворка и точные свидетельства совместимости, но никогда не определяет ваши инструменты, потоки данных, подписки, логику ордеров или модель исполнения.

## Границы пользовательских стратегий

Вы полностью сохраняете владение логикой стратегий. SQV не:

- Выбирает ваши инструменты или потоки данных
- Определяет поля подписки или глубину рынка
- Определяет поведение при сбоях или правила нормализации
- Пишет логику ордеров или модели исполнения
- Проектирует вашу внутреннюю модульную структуру

Symphony предоставляет свидетельства совместимости и поддерживаемые операции. Она никогда не ранжирует стратегии и не навязывает правила платформы вашим торговым решениям.

## SOOV: Symphony Orchestra Omega Vector

SOOV — первый именованный подвектор SQV. Он представляет будущую высокопроизводительную FIX-архитектуру только на C++, основанную на прежних наработках QuanuX. SOOV планируется как ограниченный детерминированный уровень обмена сообщениями для торговой коммуникации. Подробное поведение FIX пока не является каноническим; ни FIX-сеансы, ни адаптеры потоков данных, ни интеграции с брокерами в настоящее время не реализованы.

## Будущая область действия

SQV — планируемое место для утверждённых компонентов количественного фреймворка на последующих этапах поставки. Ожидаемые направления:

- Движки бэктестинга
- C++ API брокеров
- Библиотеки индикаторов
- Количественная математика
- Архитектура потоков данных

Ничто из этого не будет реализовано, пока не будут утверждены соответствующие контракты.

## Текущий статус

SQV — это только канонический архитектурный контракт. Ни движок SQV или SOOV, ни FIX-сеанс, ни адаптер потоков данных, ни среда выполнения стратегий, ни интеграция с брокерами, ни бэктестер, ни библиотека индикаторов, ни компонент потоков данных в настоящее время не реализованы.
