Symphony Hardware Vector (SHV) владеет знаниями об аппаратных возможностях, которые помогают понять, как физическая конструкция может обеспечивать, ограничивать, переносить или расширять количественное программное обеспечение. Он охватывает процессоры, типы ядер CPU, GPU, NIC и оптоволоконные интерфейсы, материнские платы, иерархии кэша, память, NVMe и полные системные сборки. По умолчанию приоритет отдаётся оригинальным компонентам и подтверждённым вариантам начиная с 2018 года.

## Область действия и охват

SHV может охватывать любую подтверждённую физическую возможность, значимую для проектирования программ. Вы управляете профилем охвата через qxctl. Датой по умолчанию считается дата появления модели, а не предполагаемая дата производства отдельного экземпляра. Вы можете расширить, сузить, заменить или удалить этот фильтр.

## Ревизии источников и происхождение

`shv-source-engine` реализует стабильную идентичность источников, явные планы перемещения, чистую валидацию переходов, привязку к фактически захваченным байтам и графы происхождения, воспроизведённые из источников. Это операции только на чтение. Основное курирование отдаёт приоритет идентичности оригинальных компонентов и подтверждённым вариантам. Защищённая активация источников выполняется отдельно; чистый движок источников не предоставляет полномочий.

## Обмен графами и хранение

`shv-graph-adapter` предоставляет обобщённый графовый порт на C++ для обмена без потерь и структурных запросов. Долговременное хранение реализовано через SQL-базу DuckDB по умолчанию. Специализированная графовая база данных в настоящее время не выбрана.

## Границы свидетельств из PDF

`shv-pdf-adapter` извлекает квалифицированные документальные утверждения из явных таблиц PDF и повторно проверяет их по исходным байтам после обобщённого обмена графами. Общий охват PDF остаётся отдельной работой с собственной областью действия.

## Оставшаяся работа

Широкий атлас оборудования, автоматизированное получение источников, агрегация конфликтов между несколькими источниками, дополнительные драйверы баз данных для конкретных поставщиков, загрузка пользовательских плагинов и интеграция с Composer остаются задачами на будущее. Широкие сопоставления компонентов и долговременные драйверы поставщиков также остаются открытыми.
