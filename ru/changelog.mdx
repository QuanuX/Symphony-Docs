## Новые возможности

- **Движки Symphony Node Vector.** Пять независимо устанавливаемых движков на C++26 теперь охватывают идентичность Node (SNIV), ресурсы (SNRV), отношения в кластере (SCIV), имена (SCNV), а также композицию и хранение SNV. Через qxctl можно администрировать предоставленные свидетельства, выбранные представления и сохранённую историю. Живое наблюдение и подготовка ресурсов через SOV пока не включены. См. [Node Vector](/ru/vectors/snv).
- **Необязательный локальный наблюдатель SNV.** qxctl может вызывать отдельный локальный наблюдатель, который сообщает выбранные наблюдения за CPU и памятью с явно указанной неопределённостью. Он никогда не назначает идентичность, членство или имена.
- **Основы исследовательских данных SQV.** Новые библиотеки на C++26 охватывают захват с исходными байтами и происхождением источника (SQAV), метаданные (SQMV), поток (SQFV), точное целочисленное преобразование с сохранением родословной (SQTV), локальное хранение (SQPV) и доставку с контрольными точками и точным возобновлением (SQDV). См. [Quantitative Vector](/ru/vectors/sqv).
- **Администрирование SQV через qxctl.** Семь независимо устанавливаемых движков администрирования предоставляют проверку запросов и конфигурации, проекции метаданных и инспекцию сохранённого состояния только для чтения. См. [Команды векторов](/ru/qxctl/vector-commands).
- **Адаптеры Databento и брокеров.** SQV теперь поддерживает захват Databento DBNv3 MBO, сохраняет образцы DBNv1 и DBNv3 и планирует ограниченные исторические запросы со свидетельствами покрытия. Также доступны адаптеры чтения для неживых источников и брокеров. Аутентифицированное выполнение у провайдера и живой сбор данных остаются задачами на будущее.

## Обновления

- **Допуск учётных данных в SSIAG.** SSIAG добавляет одноразовые ограничители использования учётных данных, допуск аутентифицированной диспетчеризации, надёжный журнал запросов учётных данных с восстановлением и нативную проверку пиров в macOS. Операционное использование учётных данных остаётся отключённым. См. [SSIAG](/ru/governance/ssiag).
- **Покрытие команд qxctl.** В qxctl теперь 399 стабильных идентичностей команд вместо 383. Привязки движков поддерживают 13 установленных ролей, включая пять движков SNV. См. [Обзор qxctl](/ru/qxctl/overview).
- **Пакетный интерфейс SQFV.** Пакетная библиотека SQFV теперь использует API на C++26 вместо C ABI. Обновите все интеграции, которые вызывали прежний интерфейс.
- **Ёмкость SKVI.** [SKVI](/ru/skv/skvi) индексирует больше поверхностей, включая новых владельцев исследовательских данных SQV.
- **Руководство по установке движков.** В руководстве по установке теперь уточняется, что каждый движок устанавливается, обновляется и удаляется по отдельности. См. [Обзор движков](/ru/engines/overview).
