Каждый активный вектор Symphony прикладного уровня может иметь независимо устанавливаемый движок на C++, работающий вне процесса. Общие механизмы на C++ без полномочий находятся в `libraries/`; отдельный координатор на C++ отвечает за механизмы аутентифицированных сессий и согласования рабочих деревьев. Движки инспектируют, проверяют, проецируют и предлагают в рамках контрактов, которыми владеют векторы. Они не получают полномочий лишь потому, что генерируют содержимое.

## Семейство движков SKV

Каждая поверхность SKV имеет собственный движок:

- Движки SKVI, SCLV, SACV, SODV и SSFV реализуют inspect, check, propose, project (и recovery, где применимо).
- Движки SAV и SEV — процессы «замороженного» пути на C++26 для оценки композиции и сценариев эволюции.

<Note>
  Каждый текущий движок SKV работает только в режимах чтения, запроса, проверки и предложения. Программное каноническое применение остаётся отключённым, пока для каждого движка не будут завершены контракты проверки разрешений SSIAG, транзакций с ожидаемым состоянием, защитного механизма qxctl, события STAV, восстановления и негативных тестов.
</Note>

## Общие гарантии

- Независимая установка и удаление для каждого модуля
- Никакого обхода репозитория по окружению; обнаружение манифестов явное
- Никаких общих полномочий; каждый маршрут изменений контролируется SSIAG и STAV
- Никакого присутствия на горячем пути; движки никогда не вносят задержку в живые рабочие нагрузки
