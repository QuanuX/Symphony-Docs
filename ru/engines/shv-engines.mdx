Движки Symphony Hardware Vector (SHV) каталогизируют процессоры, топологию CPU, кэши, GPU, NIC и оптоволоконные интерфейсы, материнские платы, оперативную память и NVMe. Курирование по умолчанию отдаёт приоритет оригинальным компонентам и подтверждённым свидетельствами вариантам. Каждый движок устанавливается независимо и работает только на чтение.

## Основные аспекты администрирования

- **Долговременное хранилище** администрируется только через `shv graph store inspect|prepare|commit|status|query|export|schema|template`. `commit` с сохранённым дайджестом ожидаемого намерения также служит восстановлением; отдельного псевдонима для восстановления нет.
- **Публикация каталога** администрируется только через `shv catalogue publication inspect|plan|apply|status|schema|template`. Восстановление выполняется командой `apply --operation-id`, которая взаимоисключающая с `--input`.
- **Инвентаризация** (релиз 0.2) добавляет `shv graph store inventory`: логическое чтение, привязанное к ревизии, с явными сохранёнными идентичностями записывающих сторон. Устаревший выбор из версии 0.1 по-прежнему поддерживается.

<Note>
  Классы оборудования — это данные сопоставления и профилей вызывающей стороны, а не дублирующиеся деревья команд. `--version` выбирает точного основного владельца; `--source-version` и `--adapter-version` указывают отдельные выбранные зависимости. Ревизии схем и сопоставлений — это идентичности данных, а не псевдонимы установленных версий движков.
</Note>
