`libraries/knowledge-vector-engine-cpp` предоставляет общие механизмы на C++ без полномочий, которые повторно использует каждый векторный движок Symphony. Она предлагает детерминированные строительные блоки, благодаря которым каждый движок остаётся ограниченным, воспроизводимым и свободным от побочных эффектов окружения.

## Что предоставляет основа

- **Обрамление процессов**: локальный протокол процессов без полномочий, используемый каждым движком
- **Ограниченный JSON**: строгий разбор и вывод с явными ограничениями размера и глубины
- **SHA-256**: адресация по содержимому для свидетельств и квитанций
- **Чтение без перехода по ссылкам**: чтение файловой системы, которое никогда неожиданно не проходит по символическим ссылкам
- **Детерминированные снимки**: воспроизводимые снимки инспектируемого состояния
- **Временная валидация**: каноническая обработка UTC согласно Symphony Temporal Semantics Contract
- **Обнаружение манифестов владельцев**: точное обнаружение манифестов контрактов
- **Версионированная упаковка**: независимо устанавливаемые пакеты, принадлежащие квитанциям
- **Квитанции и удаление по квитанции**: удаление выполняется только на основании квитанции, по которой был установлен артефакт

## Граница обнаружения манифестов

<Warning>
  Обнаружение манифестов начинается с фиксированного начального набора и проходит только по явным подчинённым объявлениям. Оно никогда не выполняет обход репозитория по окружению и не выводит владение из имён каталогов.
</Warning>

Каждый векторный движок, использующий основу, наследует это правило.

## Чего основа не делает

- Она не несёт полномочий. Движки, использующие её, по-прежнему должны авторизовать изменения через SSIAG.
- Она ничего не публикует и не загружает по сети.
- Она не изменяет канонические файлы самостоятельно.
