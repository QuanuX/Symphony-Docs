Symphony TOPS Audit Vector (STAV) определяет протокол журнала аудита только для добавления для каждого TOPS. Его исполняемый орган находится в `modules/stav-append-authority` — независимо устанавливаемом сервисе на Go. Операционные журналы каждого TOPS приватны для соответствующей установки TOPS; они не являются содержимым SKV.

## Орган добавления STAV

`modules/stav-append-authority` предоставляет:

- Журналы аудита только для добавления для каждого TOPS
- Взаимно аутентифицированный локальный IPC
- Точные разрешения для производителей и читателей
- Долговечность по принципу fsync до выдачи квитанции
- Ограниченное чтение, проверку и восстановление
- Регистрацию и нативную супервизию (launchd, systemd)

<Warning>
  qxctl никогда не получает прямых полномочий на добавление. Он координирует регистрацию, проверку и выдачу разрешений через точный адаптер, принадлежащий модулю, но добавление в журнал остаётся запечатанным внутри процесса органа добавления.
</Warning>

## Протокол STAV для Go

`libraries/stav-protocol-go` — это библиотека на Go без полномочий, реализующая канонический кодек STAV v1, строгую валидацию, дайджесты, обрамление, правила соответствия и закрытый словарь производителей. Любой производитель или читатель может использовать протокол, не наследуя полномочий.

## Завершённые публикации SODV

Каждый артефакт STAV, опубликованный в настоящее время через SODV, — это версия модуля исходного кода на Go, а не бинарный релиз:

- `libraries/stav-protocol-go` v0.2.0
- `modules/stav-append-authority` v0.1.0
- `modules/stav-append-authority` v0.2.0
