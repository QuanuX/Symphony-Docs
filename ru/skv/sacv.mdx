Symphony API Contract Vector (SACV) управляет версионированными API-контрактами на всей платформе. Его движок — независимо устанавливаемый процесс на C++, который выполняет ограниченную валидацию JSON по OpenAPI 3.2.0, детерминированные сравнения совместимости и формирует одноразовые инвентари. Семантика конечных точек остаётся за вектором или модулем, владеющим доменом; SACV управляет формой контрактов и совместимостью.

## Операции

- **Inspect и check**: проверить, что JSON-документ OpenAPI 3.2.0 соответствует ограниченному профилю.
- **Diff**: вычислить детерминированные различия совместимости между версиями контракта.
- **Propose**: принять объявленные вызывающей стороной предложения для реестра о новых или изменённых контрактах.
- **Project**: выдать одноразовые инвентари для рецензентов и последующих инструментов.

## Чем управляет SACV

SACV ограничивает:

- Форму контракта (OpenAPI 3.2.0 с профилем SACV)
- Классификацию совместимости между версиями
- Членство принятых контрактов в реестре

Он не:

- Владеет семантикой конечных точек (она остаётся за каждым вектором или модулем)
- Генерирует SDK, публикует артефакты или выдаёт токены
- Подразумевает существование работающей сетевой поверхности (упоминание будущего частного API не создаёт его)

<Note>
  SACV поддерживает только чтение, запросы, валидацию и предложения. Программное каноническое применение отключено во всех движках SKV.
</Note>
