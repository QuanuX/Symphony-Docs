Symphony представляет собой quantOS с открытым исходным кодом, разработанная по Vector-Graph Application Architecture. Нативные движки и SDK выполняют предметную работу; qxctl предоставляет агентам и людям общую поверхность управления. Пользователи сами выбирают движки, стратегии, поставщиков и топологию.

## Публичная бета-версия {#public-beta}

Опубликованный выпуск: **0.2.0-beta.1**, выпущен 16 ноября 2026 г. Он содержит 59 пакетов по умолчанию для каждого точного профиля, нативный клиент Codex, экспорты SDK и необязательный соответствующий исходный код.

## Возможности для изучения {#capabilities-to-explore}

- Манифесты qxctl, версии, проверка установленных владельцев и явное администрирование.
- Захват, метаданные, поток, преобразование в целые числа, локальные хранилища, воспроизведение и контрольные точки SQV.
- Ограниченные исследования бэктестов, перепись, нативная оценка, сохранённые результаты, отмена и восстановление SBV.
- Каталоги оборудования SHV с опорой на источники, требования, графы и предпросмотр публикаций.
- Знания о поставщиках SCV, а также идентичность Node, ресурсы, связи кластеров и именование SNV.
- Авторизация SSIAG, доказательства аудита STAV, композиция и управление знаниями.

## Границы квалификации {#qualification-boundaries}

Запись о выпуске определяет точные квалифицированные байты. Физический DGX Spark, поведение GPU и рабочие развёртывания у поставщиков требуют отдельных доказательств. В общей доставке учётных данных и нативных мостах к поставщикам есть явно указанные пробелы реализации; установка адаптера не квалифицирует рабочее подключение. Исправления в основной ветке исходного кода не заменяют подписанные бета-артефакты.

Перед эксплуатацией прочитайте [актуальный README исходного кода и заметки по сопровождению](https://github.com/QuanuX/Symphony#readme), а также спецификацию каждого выбранного модуля.
