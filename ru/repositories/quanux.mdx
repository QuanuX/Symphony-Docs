Этот публичный репозиторий содержит прежний снимок количественного приложения QuanuX с целевой предварительной версией v0.0.1-pre. Его README описывает сервер на Python, клиентские инструменты Node/pnpm и путь разработки настольного приложения на Tauri.

## Не смешивайте выпуски {#keep-the-releases-distinct}

Прежний пакет Conda quanux и инструкции по настройке приложения относятся к этому снимку. Они не являются способом установки Symphony Public Beta 0.2.0-beta.1.

Для текущего нативного выпуска Symphony используйте [загрузки Symphony и точные профили Anaconda](https://quanux.org/downloads) и [руководство по тестированию бета-версии](https://quanux.org/beta).

## Изучите снимок {#explore-the-snapshot}

Используйте README, лицензию, манифесты зависимостей и зафиксированную ревизию исходного кода этого репозитория при изучении его архитектуры или воспроизведении исторического поведения. Его экспериментальные API и модель приложения нельзя незаметно переносить в текущую архитектуру Symphony или в утверждения о готовности.
