Этот репозиторий содержит расширение Gemini CLI для прежнего приложения QuanuX. Его README описывает загрузку контекста GEMINI.md, генерацию пакетов стратегий на Python в server/strategies и проверку состояния движка среды выполнения.

## Оценка исходного кода {#source-evaluation}

В репозитории описаны зависимости Python и подключение расширения к Gemini CLI. Прочитайте его актуальный README и файлы зависимостей, проверьте расширение и протестируйте его с соответствующим снимком приложения в изолированном рабочем пространстве.

## Связь с Symphony {#relationship-to-symphony}

Этот проект отличается от нативного бета-клиента Symphony и не подтверждает совместимость с подписанным набором пакетов 0.2.0-beta.1. Для текущего квалифицированного клиента Symphony используйте [загрузки бета-версии и настройку клиента](https://quanux.org/downloads). Рассматривайте пути устаревшего приложения и примеры команд как относящиеся к этому репозиторию, а не как универсальные контракты Symphony.
