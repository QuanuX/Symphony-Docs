Этот репозиторий отвечает за дистрибуцию и доказательства выпуска Symphony. Публичная бета-версия **0.2.0-beta.1** опубликована 16 ноября 2026 г.

## Загрузка и установка {#download-and-install}

Используйте [quanux.org/downloads](https://quanux.org/downloads), чтобы получить установщики для платформ, инструкции по Anaconda и описания всех пакетов. [Страница выпуска](https://github.com/QuanuX/symphony-distribution/releases/tag/v0.2.0-beta.1) определяет точные артефакты.

Профили: macOS 15 ARM64, Ubuntu 24.04 AMD64, Ubuntu 24.04 ARM64 и Ubuntu 26.04 AMD64. Каждый включает 59 независимо сопровождаемых пакетов по умолчанию и необязательный соответствующий исходный код. Когорты Linux AMD64 используют общий подкаталог Conda, но являются разными квалифицированными сборками: используйте явный список точного профиля.

## Проверка и первое использование {#verification-and-first-use}

1. Прочитайте [руководство по установке](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md).
2. Проверьте подписанный манифест, индекс выпуска и выбранные файлы закреплённым средством проверки.
3. Установите в новый закрытый префикс от имени обычного пользователя.
4. Сохраните проверенные бинарные файлы в отдельном закрытом каталоге хранения.
5. Проверьте сгенерированную конфигурацию клиента и явно выберите нативных владельцев и полномочия.

Conda 26.10.0 прошла квалификацию. Для проверки и настройки нужны Python 3.11+ и OpenSSL; компилятор для запуска поставляемых бинарных файлов не требуется. Пакет PKG для Mac не подписан Apple Developer ID и не нотаризован. Отсоединённая проверка не изменяет доверие системы.

## Доказательства жизненного цикла {#lifecycle-evidence}

Выпуск квалифицирует пути установки и первого использования, 22 сценария Codex и 182 транзакции обслуживания пакетов на профиль. Ревизия 0 → 1 → 0 использует идентичные нативные байты. Обновления до других нативных версий, сохранённые копии и жизненные циклы запущенных владельцев остаются отдельными. См. [руководство по сохранению](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/RETENTION.md).
