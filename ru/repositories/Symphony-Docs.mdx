Этот репозиторий является источником сайта Mintlify по адресу [docs.quanux.org/symphony](https://docs.quanux.org/symphony). Он содержит доктрину платформы, архитектуру, справочные материалы по векторам и владельцам, документацию qxctl, переводы и материалы журнала изменений.

## Назначение репозитория и статус выпуска {#repository-purpose-and-release-status}

Symphony-Docs является репозиторием документации. Он не входит в выпуск программного обеспечения Symphony.

- В репозитории нет выпусков, тегов или пакетов GitHub. Из него ничего не устанавливается.
- Он не поставляет движки, SDK, бинарные файлы qxctl или профили Anaconda. Они входят в основной выпуск Symphony.
- Его файл `LICENSE` содержит лицензию MIT, унаследованную от стартового шаблона Mintlify. Основное программное обеспечение Symphony публикуется под лицензией AGPL-3.0 в [QuanuX/Symphony](https://github.com/QuanuX/Symphony).
- В репозитории нет README. Точкой входа для пользователей служит опубликованный сайт.

Основная публичная бета-версия Symphony, **0.2.0-beta.1**, выпущена 16 ноября 2026 г. Объём выпуска и границы квалификации описаны на [странице репозитория Symphony](/ru/repositories/Symphony). На [странице GitHub Releases репозитория QuanuX/Symphony](https://github.com/QuanuX/Symphony/releases) нет ни одного выпуска. Бета-артефакты можно получить на [quanux.org/downloads](https://quanux.org/downloads). Страница в этом репозитории описывает возможность. Она не квалифицирует эту возможность. Предложения, пункты дорожной карты и поведение оборудования или GPU, описанные на этих страницах, не являются проверенными возможностями, если об этом не сказано в записи основного выпуска.

## Документация публичной бета-версии {#public-beta-documentation}

Начните с [руководства по возможностям бета-версии](https://quanux.org/beta), затем перейдите к [загрузкам и установке через Anaconda](https://quanux.org/downloads), а после этого переходите к документации выбранного модуля.

Каждый движок устанавливается, обновляется и удаляется отдельно. Выбирайте и комбинируйте нужные движки. См. [Обзор движков](/ru/engines/overview).

## Навигация по документации {#navigate-the-documentation}

На сайте три вкладки:

| Вкладка | Содержание |
| --- | --- |
| Документация | Начало работы, Основные концепции, Knowledge Vector (SKV), Операции и инфраструктура, Идентичность, аудит и управление, Движки и библиотеки и Публичные репозитории |
| qxctl CLI | Обзор qxctl и справочники команд, начиная с [обзора qxctl](/ru/qxctl/overview) |
| Журнал изменений | Датированные заметки о выпусках в [журнале изменений](/ru/changelog) |

Используйте переключатель языка, чтобы переключаться между английским и 35 переводами. Группа Public repositories есть на каждом языке.

У каждого публичного репозитория QuanuX есть отдельная страница в разделе «Публичные репозитории». Англоязычные страницы репозиториев публикуются по адресу `docs.quanux.org/symphony/en/repositories/<repository-name>`. В переведённых страницах репозиториев вместо `en` используется код языка, например `docs.quanux.org/symphony/de/repositories/<repository-name>`. Эта страница находится по адресу [/ru/repositories/Symphony-Docs](/ru/repositories/Symphony-Docs).

## Происхождение источников {#source-provenance}

Каждой опубликованной странице соответствует один файл MDX в этом репозитории.

- `docs.json` определяет конфигурацию сайта, вкладки, группы, порядок страниц и языки.
- Английские страницы находятся в корне репозитория, а также в `concepts/`, `skv/`, `vectors/`, `governance/`, `engines/` и `qxctl/`.
- Переводы повторяют английскую структуру в языковых каталогах, таких как `de/`, `ja/` и `zh-Hans/`.
- Англоязычные страницы репозиториев находятся в `en/repositories/`. Переведённые страницы репозиториев находятся в `<locale>/repositories/`, например `de/repositories/`.
- `.mintignore` исключает черновые материалы (`drafts/` и `*.draft.mdx`) из опубликованного сайта.
- В `changelog.mdx` записи только добавляются. Новые записи добавляются в начало текущего года, а опубликованные записи никогда не редактируются и не удаляются.

Чтобы проследить утверждение, откройте соответствующий файл MDX на GitHub и изучите историю его коммитов. Утверждения о функциях восходят к основному исходному коду Symphony и его опубликованным артефактам выпуска, а не к этому репозиторию.

## Дисциплина источников и публикации {#source-and-publication-discipline}

Готовность определяется текущей реализацией в репозитории и точными опубликованными артефактами выпуска. Историческая документация и обновления основной ветки исходного кода представляют собой разные доказательства. Сохраняйте происхождение версий, отличайте необязательные сопутствующие компоненты от содержимого бинарного выпуска и сохраняйте существующие переводы и ссылки на исходный код при обновлении страниц.

Прежний репозиторий [quanux](/ru/repositories/quanux) представляет собой историческую работу. Его документация не описывает текущий Symphony.

Автоматические обновления репозиториев запланированы в 30-минутных стартовых окнах 17 и 18 ноября 2026 г., начиная с 00:01 America/New_York. Страницы будут меняться по мере появления новых доказательств и выпусков.
