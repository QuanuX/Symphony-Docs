O grupo `qxctl knowledge ...` é responsável pelo ciclo de vida entre vetores e pela administração persistente de sessões SSFV. Ele é o ponto de entrada para operações apoiadas pelo coordenador e para consultas de invariantes ao validador.

## Transição de sessão

Use `qxctl knowledge session transition` para sinalizar um evento de ciclo de vida do host a uma sessão existente:

```bash Session transition
qxctl knowledge session transition --event login|refresh|logout --event-id ID
```

Novas tentativas seguras reutilizam o mesmo ID de evento. Adicione `--recover` somente quando a intenção for a recuperação por descoberta a partir de evidências de sessão locais danificadas; ele não recupera negações, estados críticos incompatíveis nem ambiguidades.

<Warning>
  O Symphony não instala um hook de login, um watcher nem uma unidade de boot por meio deste comando. Use-o somente quando uma integração explícita com o ciclo de vida do host fornecer uma identidade de evento estável.
</Warning>

## Consultas de invariantes

Quatro folhas vinculam `ssfv:symphony:qxctl.invariant-assurance`:

```bash Invariant queries
qxctl knowledge invariant status
qxctl knowledge invariant list
qxctl knowledge invariant show
qxctl knowledge invariant check
```

`check` vincula adicionalmente `ssfv:symphony:symphony-validator.invariant-ownership-assurance`.

As folhas de consulta direta emitem `symphony.knowledge.invariant-query-result.v1` com `semantic_validity=not_asserted`. `check` retorna o resultado exato e completo do validador e preserva o código de saída 26.
