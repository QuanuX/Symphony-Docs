Este projeto fornece uma ponte MCP nativa em C++, catálogos de ferramentas, geradores de configuração de clientes e skills para operações locais do Symphony por meio do qxctl. Ele preserva o roteamento exato para proprietários e a autoridade explícita.

## Comece com o cliente beta {#start-with-the-beta-client}

Para o caminho binário qualificado, use o cliente fornecido no [Symphony 0.2.0-beta.1](https://quanux.org/downloads). Siga o [guia de retenção e configuração do cliente](https://downloads.quanux.org/symphony/0.2.0-beta.1/docs/BETA-INSTALL.md). O Codex é o principal cliente qualificado; os adaptadores de configuração existentes do Claude, do Antigravity e genéricos mantêm seus próprios limites.

## Explorar {#explore}

- Descubra ferramentas estruturadas e encaminhe operações para os proprietários do qxctl instalados.
- Gere um perfil de conexão isolado e um fragmento de configuração do cliente.
- Comece com operações de leitura; habilite a autoridade de escrita somente por meio de fluxos de proprietário documentados.
- Inspecione as skills do projeto e as instruções de build e teste no nível do código-fonte.

O contrato do protocolo está fixado neste repositório. Use a versão declarada e os pré-requisitos de build em vez de substituí-los silenciosamente por uma revisão mais recente do MCP. Um repositório público ou uma configuração de cliente local não é uma alegação de aprovação em um diretório de plugins de terceiros.
