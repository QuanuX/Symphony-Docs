Setiap vektor Symphony tingkat aplikasi yang aktif dapat memiliki engine C++ di luar proses yang dapat dipasang secara independen. Mekanika C++ bersama tanpa otoritas berada di bawah `libraries/`; koordinator C++ terpisah memiliki mekanika sesi terautentikasi dan rekonsiliasi worktree. Engine menginspeksi, memvalidasi, memproyeksikan, dan mengusulkan dalam batas kontrak milik vektor. Engine tidak memperoleh otoritas hanya karena menghasilkan konten.

## Keluarga engine SKV

Setiap permukaan SKV memiliki engine sendiri:

- Engine SKVI, SCLV, SACV, SODV, dan SSFV masing-masing mengimplementasikan inspect, check, propose, project (dan recovery bila berlaku).
- Engine SAV dan SEV adalah proses C++26 freezing path untuk evaluasi komposisi dan kasus evolusi.

<Note>
  Setiap engine SKV saat ini hanya untuk membaca, kueri, validasi, dan mengusulkan. Penerapan kanonis secara terprogram tetap dinonaktifkan hingga kontrak verifikasi izin SSIAG, transaksi status yang diharapkan, pengaman qxctl, event STAV, pemulihan, dan pengujian negatif setiap engine selesai.
</Note>

## Jaminan umum

- Instalasi dan uninstalasi independen per modul
- Tidak ada penjelajahan repositori secara ambien; penemuan manifest bersifat eksplisit
- Tidak ada otoritas bersama; setiap rute mutasi dijaga oleh SSIAG plus STAV
- Tidak ada residensi hot path; engine tidak pernah menyuntikkan latensi ke workload langsung
