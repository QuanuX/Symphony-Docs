Repositori publik ini berisi snapshot sebelumnya dari aplikasi kuantitatif QuanuX, dengan target pra-rilis v0.0.1-pre. README-nya menjelaskan server Python, alat klien Node/pnpm, dan jalur pengembangan desktop dengan Tauri.

## Pisahkan rilis-rilisnya {#keep-the-releases-distinct}

Paket Conda quanux sebelumnya dan instruksi penyiapan aplikasinya merupakan bagian dari snapshot ini. Itu bukan cara instalasi Symphony Public Beta 0.2.0-beta.1.

Untuk rilis Symphony native saat ini, gunakan [unduhan Symphony dan profil Anaconda yang persis](https://quanux.org/downloads) serta [panduan pengujian beta](https://quanux.org/beta).

## Jelajahi snapshot {#explore-the-snapshot}

Gunakan README, lisensi, manifest dependensi, dan revisi kode sumber yang tercatat dari repositori ini saat menyelidiki arsitekturnya atau mereproduksi perilaku historisnya. API eksperimental dan model aplikasinya tidak boleh dipromosikan secara diam-diam ke dalam arsitektur Symphony saat ini atau klaim kesiapan.
