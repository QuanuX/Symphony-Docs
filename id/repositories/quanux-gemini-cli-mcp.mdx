Repositori ini berisi ekstensi Gemini CLI untuk aplikasi QuanuX sebelumnya. README-nya menjelaskan cara memuat konteks GEMINI.md, membuat paket strategi Python ke dalam server/strategies, dan memeriksa status engine runtime.

## Evaluasi kode sumber {#source-evaluation}

Repositori ini menjelaskan dependensi Python dan cara menautkan ekstensi dengan Gemini CLI. Baca README dan file dependensinya saat ini, tinjau ekstensinya, lalu uji dengan snapshot aplikasi yang sesuai di ruang kerja yang terisolasi.

## Hubungan dengan Symphony {#relationship-to-symphony}

Proyek ini berbeda dari klien beta native Symphony dan tidak menetapkan kompatibilitas dengan kumpulan paket 0.2.0-beta.1 yang ditandatangani. Untuk klien Symphony yang terkualifikasi saat ini, gunakan [unduhan beta dan penyiapan klien](https://quanux.org/downloads). Perlakukan jalur aplikasi lama dan contoh perintah sebagai milik repositori ini, bukan sebagai kontrak Symphony yang universal.
